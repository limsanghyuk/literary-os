## Purpose
Test whether the craft doctrine that succeeded on fresh synthetic scenes remains usable when expanded to an entire broadcast-scale episode with ensemble, workplace procedure, comedy, melodrama, relationship motion, and social texture.

This unit does **not** test whether a 50-scene exact target is optimal. Scale is variable. The only frozen floors are:
- episode surface >=35,000 Unicode characters;
- sequence count >=9;
- scene count >=45;
- no fixed maximum for characters, sequences, or scenes.

## Hypothesis
Given one frozen whole-episode semantic architecture, a Treatment renderer using the conservative I4H doctrine (`ABSTAIN -> RELIABILITY -> LOW/STANDARD`) will preserve structural/semantic fidelity and ensemble voice while improving or preserving information control, physicalization, pacing, and scene pressure relative to a Control renderer using the existing baseline LiterarySurfaceContract without the I4H selector.

## Scale doctrine
The planner may naturally choose any count above the floors. For this pretest, no exact `10 sequence / 50 scene` target is allowed as a gate. An output with 11–12 sequences and 50+ scenes is valid if justified by ensemble and pacing needs.

Overlength failure is determined by redundancy, repetitive information, non-playable exposition, dialogue treadmill, or pacing collapse—not a hard maximum.

## Scene doctrine
`Scene Surface = Action/Direction + Dialogue`.

Dialogue is not required to be short. Dialogue should remain when it performs:
- character voice;
- humor;
- intimacy;
- conflict tactic;
- status negotiation;
- social/ensemble texture;
- relationship action.

Audience-facing explanation may move into playable/filmable direction when that improves dramatic information.

## Treatment doctrine
For every scene, before Treatment prose:
1. choose `ABSTAIN` or `INTERVENE`;
2. if INTERVENE, choose LOW or STANDARD before prose;
3. generate treatment;
4. run reliability gate;
5. reject unreliable treatment and fall back to Control bytes rather than silently repairing after judgment.

Strong abstention prior is retained. Intervention density is diagnostic, not a pass threshold; the experiment may not force a target percentage.
