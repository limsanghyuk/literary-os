## 4. Mode routing rules
- investigative/interpersonal questioning or leverage shifts -> `ELICITATION_PRESSURE`;
- quiet relational scenes where non-speech/action carries emotion -> `EMOTIONAL_WITHHOLDING`;
- professional task scenes where work must advance by concrete actions -> `OCCUPATIONAL_EXECUTION`;
- explicit countdown/deadline scenes -> `DEADLINE_KINETICS`;
- staged discovery whose meaning changes across beats -> `REVEAL_REVERSAL`;
- hierarchy/power scenes where status movement is the dramatic event -> `STATUS_DOMINANCE`;
- urgent procedural scenes requiring command -> immediate action -> consequence -> `URGENT_COMMAND_ACTION`;
- multi-character coordinated causal work -> `TEAM_EXECUTION`;
- terminal/convergence scenes whose final beat raises next-episode cost -> `EXIT_ESCALATION`;
- otherwise -> `NONE`.

If multiple rules match, select the mode corresponding to the scene's dominant frozen turn/exit mechanism, not the most elaborate mode.
