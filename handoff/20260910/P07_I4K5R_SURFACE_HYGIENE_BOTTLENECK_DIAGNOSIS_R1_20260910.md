## 2. Root cause
This is a render-boundary integration omission, not evidence that Event Ecology structure is harmful.

The active research lineage already had a successful `LiterarySurfaceContractR1` interface from I4B targeting `INTERNAL_NARRATIVE_CONTROL_LOGIC_TO_SURFACE_EXPOSITION_LEAK`, and I4D used targeted `SurfaceRealizationModeR1` craft operators with exact-long-duplicate mechanical checks. But the I4K-4 whole-episode prereg/execution contains no explicit `LiterarySurfaceContractR1`, `SurfaceRealizationModeR1`, or equivalent surface-firewall consumption/validation step.

I4K-4 Render Admission checked only structure/scale/adoption: exactly 10 sequences, 50 scenes, anchors, >=35k file-level Unicode chars, no major unplanned event, Treatment adoption, Control contamination=0, and <=10% length gap. It did **not** gate duplicated plan prose, plan/meta token leakage, plan-to-surface copy overlap, procedural vocabulary density, or scene-local playability.

Therefore planning semantics were preserved, but planning-language serialization leaked into the broadcast surface.
