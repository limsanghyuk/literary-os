## 4. D1 causal conclusion

The missing capability is not missing research.

The regression occurred when the active E6/R3 planning contract collapsed rich upper-layer semantics into:
`episode objective -> sequence goals -> scene obligations/turns`.

That compression makes one parent objective disproportionately powerful. The planner can still generate varied local scenes, but the episode can remain a single task tree.

The project had already warned about this exact family of error in two historical forms:
- sequence formulas can determine counts but not dramatic judgment;
- data/schema existence is not enough without a negotiated consumer contract.

## 5. D1 repair applied

R3-D preregistration now reinstates explicit H0-H4 planning contracts:
- H0 Series/Writer-room;
- H1 Episode Architecture;
- H2 Multi-story/Ensemble Allocation;
- H3 SequenceBlueprint;
- H4 Sentinel Scene Contracts.

It also adds anti-collapse gates before any new screenplay surface is legal.
