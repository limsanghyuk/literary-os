## Purpose / 목적
Before beginning fresh SYNC-R77 architecture requalification, re-audit all material upper-layer defects that can invalidate an apparently rich Episode/Sequence/Scene architecture.

## A. Flattening / 평탄화 — UL14
Historical defect:
rich narrative state -> few plot-line labels -> one owner/counterparty per sequence -> uniform obligations -> deterministic 2/3-scene lowering.

Risks:
- single causal spine disguised as multiple subproblems;
- relationship/social/information obligations becoming checks rather than generative causes;
- deferred debt recorded in a ledger but absent from actual sequence pressure.

Current requirement:
- preserve independent causal roots;
- allow multi-owner/multi-kind sequences only when justified;
- preserve independent strands when weaving would flatten meaning;
- variable depth must emerge from unique material, never quota padding.

## B. Semantic preservation / 의미 보존 — UL16 R3
Historical defects:
- relationship/info/social deltas collapsed into generic text;
- relationship pairs/group refs lost;
- whole-sequence cast leaked into local scenes;
- deferred residue vanished at lowering boundary;
- owner concentration metric overcounted joint participation.

Current requirement:
- concrete semantic deltas/topology survive Episode -> Sequence -> Scene -> Canonical IR;
- transaction-local actors/owners;
- deferred residue preserved;
- no false owner monopoly.

## C. Scene-depth overcorrection / 장면 깊이 과교정 — R57/R58

## F. Temporal / spatial continuity / 시간·공간 연속성 — PA7/PA8
Historical defect:

Current requirement:

- future ETA/event must not fall behind current scene time;
- location transitions must be explicitly feasible;
- character presence/location carry must be coherent;
- no surface renderer is allowed to repair an upstream chronology contradiction.

## G. Information asymmetry / 정보 비대칭
Historical risk:

Current requirement:

- no omniscient leakage;
- private information need not be revealed merely to satisfy a coverage metric.

## H. Social ecology / 사회 생태
Historical risk:
supporting characters and groups become instruments of protagonist/main plot.

Current requirement:

- social/institutional obligations require concrete operational consequences;
