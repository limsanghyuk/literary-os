## Regression signatures frozen before output
### E6-type Template Collapse
The following are forbidden as a generation strategy:
- one full dialogue sentence reused mechanically across many unrelated scenes;
- one full direction block reused mechanically across many unrelated scenes;
- character names / props / locations swapped into an otherwise identical Scene template;
- fixed per-scene role slots masquerading as ensemble diversity.

Operational audit:
- exact repeated non-motif full dialogue/direction lines across >=5 distinct scenes => automatic FAIL;
- normalized duplicate Scene transaction signature => FAIL unless explicitly justified as intentional dramatic repetition and independently accepted by reviewers.

### E3-type Procedural Monoculture
The screenplay must not resolve heterogeneous conflicts through one dominant procedure such as `confirm -> record -> verify -> sign`.

Audit the distribution of Scene-driving mechanisms, including at least:
- direct conflict / refusal;
- deception or withheld information;
- relationship choice / betrayal / loyalty;
- institutional or social-group pressure;
- physical task / risk / failure;
- discovery / information asymmetry;
- negotiation / exchange / sacrifice;
- mistake / unintended consequence;
- aftermath / payoff / debt creation.

This list is an audit taxonomy, not a quota. The presence of labels alone does not satisfy diversity; the underlying causal transaction must differ.
