# 2. 실험별 상세 (가설 → 방법 → 절차 → 결과 → 산출물)

## CT-06H — top-down 관문(얇은 설계)
- **가설**: 시퀀스 설계(5필드)만 주면 시스템이 씬카드를 생성할 수 있고, 그것으로 렌더한 대본이 사람 씬카드에 근접한다.
- **방법**: 4팔 — A(설계 없음)/B(사람 씬카드)/B″(생성 씬카드)/N″(불일치 설계로 생성). 홀드아웃 10씬. 판정식 r=(B″−A)/(B−A), 임계 r≥0.70 성립·r≤0.30 불성립.
- **절차**: 정본 DB에서 패킷 재구성·sha 봉인 → GPT-5가 씬카드 130매 생성(컨텍스트 분리) → Sonnet 격리 렌더 40본 → 블라인드 3인 채점(49요소) → 개봉.
- **결과**: **r = 0.211 → 불성립.** A=0.000·N″=0.000(암기 없음·틀린 설계 무효)·B=1.425·B″=0.300. 생성 카드는 goal만 간헐 전달, **conflict·info는 0건**.
- **산출물**: `05_RAWDATA/ct06h/`(패킷·생성 130매·렌더 4팔·채점 3인·봉인 맵)

## CT-07 — 설계 깊이 응답 곡선 ★전환점
- **가설**: CT-06H의 실패 원인은 구조가 아니라 **설계도의 얇음**이다. 필드를 늘리면 성립한다.
- **방법**: 7팔 단일 배치 — 없음/박판(GPT-5)/박판(Gemini)/**후판 생성**/사람 카드/**후판 직접**/**정답표=설계도(천장)**. 후판 10필드 = 5필드 + cast·event·info_shift·plant_payoff·scene_notes.
- **절차**: 격리 저작자가 원문 정독으로 후판 저작·봉인 → Gemini 생성 → 격리 렌더 → 70본 단일 블라인드 배치 3인 채점.
- **결과**: **r_L2G = 0.807 성립**(양작 0.81/0.80). **후판 직접 렌더 r=1.63 > 사람 씬카드 1.00**, 천장(정답표 설계도) 4.90/5. 분해: **깊이 효과 +0.74 지배**, 생성기 효과 −0.07 무시, **생성 손실 +0.83**(씬카드 1문장 압축이 병목).
- **의미**: 현재 THICK 10필드 사양의 실측 근거. **얇으면 낳지 못하고 두꺼우면 낳는다.**
- **산출물**: `05_RAWDATA/ct07/`

## CT-11 / 11B / 11C — 회차 구성(경계·개수) 자율 설계
- **가설**: 회차 설계층과 다른 작품 사례를 주면 시스템이 사람 작가처럼 시퀀스 경계를 그을 수 있다.
- **방법**: **전량 결정론 채점**(정답이 정본에 있으므로 LLM 심판 불요). 경계 F1(±1)·개수 오차·IoU. 기준선 = 균등분할.

  - CT-11B: 2단(k추정→경계) + 오라클-k 분해팔 × 4작 12회차
  - CT-11C: **k를 결정론 회귀로 고정** + 장르 2층화 × 6작 12회차
- **결과**:

# 3. 방법론 자산 (다른 실험에 재사용 가능)

## 3-1. 채점 규약 v2 (`04_STANDARDS/SCORING_PROTOCOL_V2`)
- **문제**: 요소가 길고 복합적이라 채점자마다 갈림(D-53). 이진 일치도가 기저율로 부풀려짐(D-54).
- **처방**: ①요소를 **원자 서브 명제**로 분해 ②불성립 조건을 **폐쇄 목록**으로 ③역할 교체 허용을 **플래그로 명시** ④1점 준 서브마다 **근거 인용 의무** ⑤다수결 폐지, **조정자**가 불일치만 재판정(반려권 보유) ⑥게이트는 **비자명 일치도**만 사용.
- **검정**: 캘리브레이션에서 **0.900**(v1 0.77~0.84) — 3게이트 통과.

## 3-2. 시퀀스 표준 v1 (`04_STANDARDS/SEQUENCE_STANDARD_V1`)
- **진단**: GPT 스키마에도 우리 저작 스펙에도 **시퀀스의 단위 정의가 없었다**(전자는 필드만, 후자는 씬 경계만).
- **정의**: 시퀀스 = **하나의 극적 거래**. 판정문 "이 묶음을 지우면 회차의 상태 서술이 바뀌는가".
- **경계 규칙 B1~B5** + **안티패턴 3금지**(등간격 맞추기·장소만으로 끊기·브레이크 정렬).
- **신설 필드 `boundary_reason`** — B코드 + 근거 씬번호. 이게 없으면 경계는 영원히 검증 불가.
- **게이트 G1~G5**(결제 유일성·경계 근거·**등간격 경보 cv<0.08**·인물 접지·정보 원장 정합).
- **합격 조건**: CT-12C에서 주석자 간 일치 0.737 → **0.85 이상**. 미달 시 제안 상태 유지.

## 3-3. 결정론 도구 (`06_TOOLS/`)
- `score_design_g2pp.py` — 설계 채점(전환유형 적중·의도 근접), API 불요.
