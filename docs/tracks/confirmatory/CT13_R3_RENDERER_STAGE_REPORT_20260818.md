## 4. 공시할 이탈·주의 (정직 기록)
1. **N팔 처리의 세션 간 편차**: 렌더러 1·3은 자기보고에서 "불일치 계획의 **구조만** 현재 작품 인물·스레드에 이식했고 고유명사는 가져오지 않았다"고 진술. 렌더러 4·5·6도 유사(구조 이식·수리 없음). 이는 "불일치 계획을 있는 그대로 실행"의 합리적 해석이나, **N을 완전한 무의미 입력으로 두지 않고 부분적으로 정합화한 것**으로 볼 여지가 있다. C vs N 대비가 보수적(=C에 불리) 방향으로 작용할 수 있음을 채점·해석 시 반드시 고려할 것.
2. **동일 모델 계열**: 렌더러 6세션 전부 claude 계열. 킷은 렌더러 계열을 규정하지 않았으나 채점자도 동일 계열이면 계열 교란이 남는다 → **채점자는 렌더러와 다른 계열 또는 최소한 별도 격리 세션**을 권고.
3. 본 세션은 렌더 호스트이므로, 규정상 **채점·언블라인딩·PASS 인증에 관여하지 않는 것이 원칙**이다.
