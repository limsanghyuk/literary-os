## 1. 가설
H1: 회차 아크를 시퀀스 설계 생성에 제공(E팔)하면, 미제공(F팔) 대비 **회차 수준 지표**가 개선된다.
H2(모델 일반성): H1의 효과는 생성 모델(Claude/GPT-5)에 무관하게 재현된다 — 즉 "측정 스코프 원칙"은 특정 모델의 버릇이 아니라 데이터 구조의 성질이다.

## 2. 설계
- **3팔**: E=직전 2시퀀스 맥락+**해당 회차** 아크 / F=맥락만 / **N=맥락+불일치 아크(같은 작품의 다른 회차 아크를 무작위 배정, 시드 고정)**. 프롬프트 템플릿=G2' 동일(5필드 설계 출력). N팔의 역할(CT-01·CT-02 교훈): E>F이며 **N≈F**일 때만 "아크 내용의 조향"이 입증된다. N≈E면 형식 효과(아크 모양 텍스트 자체)로 판정.
- **모델 2종 × 3팔**: claude(현행 API 기본 모델) · gpt-5 — 동일 표본·동일 프롬프트·temperature 0.2·팔 순서 무작위.
- **표본**: 신규 에피소드에서 **팔당 n≥48**(모델당 144 설계, 총 288). 기존 G2'/G2''에 쓰인 에피 제외(오염 방지), 작품 4+ 장르 분산, A-트랙 held 작품(시티헌터·오나의귀신님) 제외 유지.
- **채점**: `tools/measure/score_design_g2pp.py` **고정본 sha256=6a35ca49d1a6a057** — 전량 결정론, API 불요.

## 3. 주지표·임계 (사전 고정)
| 지표 | 임계(모델별 각각) |
|---|---|
| 주1 turn_match (전환유형 적중) | E가 F 대비 **상대 +50% 이상** AND E 절대값 > 우연(0.125) AND **E−N ≥ (E−F)의 절반**(내용 조향 분리) |
| 주2 intent_proximity (실제 설계 근접) | **Δ(E−F) > 0** AND **Δ(E−N) > 0** |
| 민감도(의무) | 최대 양수 기여 1건 제외 후에도 주1 상대 우세 ≥ +25% 유지 |
| 보조 format_complete | 게이트: 양팔 모두 ≥0.9 (미달 팔은 표본 재생성 1회 허용) |

**판정 매트릭스**: 두 모델 모두 주1·주2 충족 → **H1+H2 채택(법칙 확정, 정본 승격)** / 한 모델만 → H1 부분 채택·모델 의존성 기록(생성 본체 선택 근거로 사용) / 둘 다 미달 → 8/4 결과를 탐색적 노이즈로 강등(정직 기록).
