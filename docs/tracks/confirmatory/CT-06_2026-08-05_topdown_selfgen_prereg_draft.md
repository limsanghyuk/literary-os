# CT-06 사전등록 초안 — 방향 시험 + 자기생성 시험 (top-down 관문) (2026-08-05)

**상태**: 초안(집 Fable 작성) — 집행 전 회사 세션 검토·확정 후 v1.0 승격. 확정 전 데이터 생성 금지.
**이것이 "그 질문"의 시험이다**: 개발자 질문 "우리 모델이 기획·구성·설계·창작할 수 있는가"에 처음으로 숫자를 붙이는 실험. 08-05 회사 세션이 제안한 방향 시험+자기생성 시험(B″)의 통합 사전등록.

## 1. 질문과 가설
- Q1(방향): 시퀀스층 설계만 주면 시스템이 **씬층 설계(SceneCard)를 생성**할 수 있는가 — 정보가 위→아래로 흐르는 제품 방향의 첫 시험.
- Q2(자기생성): 그 생성된 씬층으로 대본을 렌더하면, 사람이 저작한 씬층(CT-01 B조건)과 같은 우위가 나오는가.
- H: B″(자기생성 씬층) 기능충실이 A(무설계, 0.70)보다 B(사람 저작, 3.20)에 유의미하게 가깝다.

## 2. 설계 (CT-01 홀드아웃 재사용 — 앵커 비교 가능)
- 홀드아웃: CT-01과 동일 10씬이 속한 시퀀스들(건빵선생과별사탕_01·한성별곡_01). 시퀀스층 설계(SequenceBlueprint 5필드+member 구성)만 입력.
- **4조건**: A=무설계(앵커 0.70) / B=사람 저작 SceneCard(앵커 3.20) / **B″=시퀀스층만 받은 프런티어가 생성한 SceneCard** / **N″=불일치 시퀀스 설계에서 생성한 SceneCard**(네거티브 컨트롤).
- 렌더·채점: CT-01과 동일 파이프(렌더러 격리·정답표 재사용·블라인드·매핑 봉인). B″/N″ 신규 렌더만 필요(A·B는 기존 앵커 인용).
- **1차 종점 = 기능충실**(08-05 세션 척도 교정 반영 — 창작 질문에 사실복원 척도 금지). 사실충실·환각은 2차(참고).

## 3. 임계 (사전 고정)
| 결과 | 판정 |
|---|---|
| B″ 기능충실 ≥ 2.5 AND B″−N″ ≥ 1.0 | **top-down 성립** — LLM-2 실현 가능의 첫 증거. 다음=회차층→시퀀스층 동일 시험 |
| B″ ≤ 1.2 (A 근방) | **불성립** — 현 스키마·현 프롬프트로는 생성 불가. 목표 수정 논의(주석 데이터셋+게이트 제품으로 축 이동) |
| 중간 (1.2~2.5) | 부분 성립 — 범주별 분해로 누수 지점 지목(goal/turn은 되고 info_shift는 새는가 등) 후 표적 보강 |
- 민감도 의무: 최대 기여 1씬 제외 후 판정 유지 확인. 채점자≠생성자 모델 분리. 표본: 씬 20+(양 작품).

## 4. 병행 저비용 시험 ①: 해석 편차 바닥값 (개발자 가설 직접 검정)
같은 사람 저작 SceneCard로 K=5회 렌더 → 생성물 간 상호 거리 vs 생성물–원작 거리 비교. 상호 거리 ≈ 원작 거리이면 "복원 24.8%는 결함이 아니라 해석의 자연 폭"이 입증됨. 전량 결정론(임베딩/문자 n-gram), API 렌더 비용만.
