# CT-14 사전등록 — 역설계 문법 부여 효과의 독립 재현 (2026-08-21, 생성 전 고정)

**문서 ID**: LOS-CT14-PREREG-V1.0 · 개발자 지시(08-21): *"원문만 준 파운데이션과, 우리가 역설계한 문법을 준 조건의 점수 차이가 정말 그 정도인가 — 역으로 실험하라."*

## 0. 왜 이 실험인가
R45R은 **U1 80.5 → U5 92.0 → L5 97.0**, 즉 Literary OS 증분을 **+4.5**로 보고했다. 그러나 R45R은 **GPT가 설계·생성·채점을 모두 수행한 내부 실험**이며(주장경계 문서가 스스로 "동일 모델 생성·평가"를 한계로 명시), **다른 계열이 재현한 적이 없다.** 본 실험은 **Claude 계열이 독립 집행**해 그 격차를 검증한다.
또한 R45R이 묻지 않은 질문을 추가한다: **이득이 "구조를 줬기 때문"인가 "맞는 구조를 줬기 때문"인가**(네거티브 대조).

## 1. 팔 (같은 표본·같은 채점, 입력만 상이)
| 팔 | 입력 |
|---|---|
| **U** | ①격리 요약자가 EP01~09 원문만 읽고 작성한 **중립 줄거리·플롯/인물별 요약**(우리 스키마 용어 사용 금지) + ②**EP09 원문 전문** |
| **L** | U 전부 + **역설계 문법 명세**(THICK 10필드 · EpisodePlan 계약 4요소[플롯 소유권·앙상블 배분·유예/부채·종단] · 경계 규칙 · 시점 적합성 · 신규성 근거) + **해당 작품의 N−1 구조화 상태**(THICK에서 추출한 미해결 스레드·부채) |
| **N (네거티브)** | U 전부 + **동일 문법 명세** + **다른 작품의 구조화 상태**(형식·분량 동일, 내용 불일치) |
- 세 팔 모두 동일 생성기(gemini-2.5-pro, 파일 접근 없음), 동일 과제: **EP10의 회차 시놉시스 + 시퀀스 구성 설계**.
- 목표 회차(EP10) 원문은 **어느 팔에도 제공하지 않는다.**

## 2. 표본
R45R 6작·기존 CT 실험 작품과 **전량 비중복**인 3작: **하얀거탑(의학·권력)·밀회(멜로)·마왕(스릴러·복수)**. 각 EP10 설계 = 3작 × 3팔 = **9 산출**.

## 4. 판정 규칙 (사전 고정)
| 관측 | 해석 |
|---|---|
| **L − U ≥ +10** | R45R이 문법 효과를 **과소평가**했다 |
