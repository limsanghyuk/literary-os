## 인물
- 준서 (PRIMARY): 목장에서 은서와 재회하지만 병을 모른 채 유미와 미국행을 준비한다.
- 은서 (OPPOSITION): 준서와 마음의 결속을 확인한 뒤 수술 공포에 무너져 혼수에 빠진다.
- 태석 (SECONDARY): 가족 검사와 치료를 실행하나 은서의 준서 호명을 견딘다.
- 강희 (SECONDARY): (기술 없음)
- 유미 (SECONDARY): 은서와 비밀 약속을 맺고 끝내 준서에게 병을 폭로한다.
