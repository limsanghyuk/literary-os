## 인물
- 윤교수 (PRIMARY): 병원에서 확인한 교환 사실을 실제 다른 가족에게 대조하려 시장으로 가고 순임에게 출생 교환 가능성을 직접 알린다.
- 경하 (PRIMARY): 친딸이 자란 환경을 직접 보게 되자 두려움과 거부감으로 신애를 만나지 않으려 하고 은서에게 돌아가려 한다.
- 준서 (PRIMARY): 은서를 괴롭힌 신애를 막으려 거래를 제안한 뒤 우연히 부모와 순임의 대화를 엿들어 출생 교환 비밀을 아이들 중 먼저 알게 된다.
- 신애 (SECONDARY): 준서의 보호 거래를 자존심 싸움으로 받아치며 무릎까지 꿇게 하지만 자신의 출생과 윤가족의 조사 목적은 모른다.
- 순임 (SECONDARY): 낯선 부부의 질문을 경계하다 자신이 키운 딸과 상대 가족의 딸이 병원에서 바뀌었다는 주장을 처음 듣는다.

## 사건
윤교수는 경하를 데리고 시장으로 가 친딸이 자란 환경과 순임을 확인하고, 순임에게 두 딸이 병원에서 바뀌었다고 직접 밝힌다. 같은 시간 준서는 은서를 괴롭힌 신애에게 그림을 그려주는 대가로 괴롭힘을 멈추라고 요구했다가, 국밥집 밖에서 부모의 출생 교환 대화를 우연히 듣고 비밀을 공유하게 된다.
