- 준서 (SECONDARY): 목장에서 은서와 재회하지만 병을 모른 채 유미와 미국행을 준비한다.
- 신애 (SECONDARY): (기술 없음)
- 순임 (SECONDARY): 병을 알고 집문서를 들고 윤가에 무릎 꿇는다.
- 태석 (SECONDARY): 가족 검사와 치료를 실행하나 은서의 준서 호명을 견딘다.
