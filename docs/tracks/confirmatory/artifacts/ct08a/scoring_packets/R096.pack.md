# 채점 패킷 R096

## 판정 대상 요소 10개

- **E01** [goal] 한 인물(약혼남)이 공식 약혼 의식을 완수하여 관계를 사회적으로 확정짓는다. 시퀀스가 끝날 때 약혼식은 중단 없이 마무리된다. 불성립: 의식이 외부 개입으로 중단되거나, 당사자가 거부 의사를 공개적으로 표명하면 불성립.
- **E02** [goal] 한 인물(호텔 직원)이 같은 호텔 내 특정 직원의 실제 신원을 능동적으로 추적하여 이 시퀀스 안에서 이름을 확인하는 데 성공한다. 불성립: 신원이 제3자의 제보로 우연히 알려지거나, 이름 확인 없이 존재 사실만 파악하면 불성립.
- **E03** [character] 약혼녀가 공개 의식 자리에서 '첫사랑'을 먼저 언급함으로써, 상대에 대한 완전한 독점 의지를 상대가 긍정하게끔 유도한다. 불성립: 약혼녀가 먼저 언급하지 않고 상대방이 먼저 꺼내거나, 독점 의미 없이 단순한 추억 대화로 끝나면 불성립.
- **E04** [character] 추적자(호텔 직원)는 신원을 확인하기 위해 핸드폰 두 대를 동시에 이용하는 우회적 수단을 직접 고안하고 실행한다. 불성립: 타인이 방법을 알려 주거나, 단순히 이름을 물어보는 정면 대결 방식을 택하면 불성립.
- **E05** [conflict] 약혼식 자리에서 약혼녀가 약혼남의 첫사랑에 대한 진실을 간접적으로 추궁하고, 약혼남은 대답을 회피하지 못한 채 첫사랑의 이름을 발화한다. 불성립: 약혼남이 이름을 끝내 말하지 않거나, 질문 자체가 없으면 불성립.
- **E06** [conflict] 추적자가 신원을 은폐하던 상대방과 대면하는 순간, 은폐자는 자기 이름을 스스로 발화해야 하는 상황에 놓인다. 불성립: 은폐자가 이름을 끝내 말하지 않거나 도망쳐 나오면 불성립.
- **E07** [info] 관객은 약혼남이 약혼녀의 '나무' 이미지와 자신의 첫사랑을 동일하게 지칭하고 있음을 알지만, 약혼녀는 그 이중 의미를 모른다. 불성립: 약혼녀가 그 이중 의미를 눈치채거나, 약혼남이 명시적으로 구분해 설명하면 불성립.
- **E08** [info] 추적자는 이 시퀀스에서 처음으로 상대방의 실제 이름을 얻는다. 이전까지는 이름 없이 '최씨 아줌마'라는 호칭만 알고 있었다. 불성립: 추적자가 이미 이름을 알고 있었거나, 이름이 아닌 다른 신원 정보만 확인하면 불성립.
- **E09** [link] 첫사랑이 누구냐는 약혼녀의 질문과 약혼남의 대답이 공중에 미결인 채 씬이 끝나, 이후 약혼녀가 첫사랑의 존재를 의식하는 서사적 기반을 만든다. 불성립: 약혼남이 명확히 '없다' 또는 '모른다'로 부정하여 긴장이 해소되면 불성립.
- **E10** [link] 추적자가 은폐자의 이름을 확인함으로써, 둘의 관계가 다음 국면에서 대립 또는 협상의 형태로 전환될 토대를 만든다. 불성립: 추적자가 이름을 알고도 같은 시퀀스 안에서 그 정보를 다른 인물에게 즉시 공개하거나 사용하면 불성립.
