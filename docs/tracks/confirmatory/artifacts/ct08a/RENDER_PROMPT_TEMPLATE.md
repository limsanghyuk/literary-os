## 과제

아래 설계 기록을 바탕으로 한국 드라마 대본 **시퀀스 하나**를 집필하라.

## 지시

1. 씬 개수는 `RENDER_SPEC.json` 이 이 블라인드 ID 에 대해 고시한 수를 **정확히** 따른다. 순서는 설계 기록에서 판단하라.
2. 각 씬은 `씬N 장소, 시간` 형식의 표제로 시작한다.
3. 지문과 대사를 모두 쓴다. 방송 대본 형식을 따른다.
4. 분량은 **씬당 22~32행** (= `RENDER_SPEC.json` 의 min_lines~max_lines).
5. 해설·요약·메모·머리말을 붙이지 말고 **대본 본문만** 출력하라.
6. 설계 기록에 없는 인물·사건을 새로 만들지 마라. 반대로 기록에 있는 것을 임의로 빼지도 마라.
7. 기록이 불충분한 부분은 작가로서 채워 넣되, 기록과 모순되게 쓰지 마라.
