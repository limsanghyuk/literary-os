## 인물
- 준서 (PRIMARY): 은서 사진을 숨기고 전시회에서 다시 보호 행동을 보인 뒤 유미에게 선택만을 말한다.
- 은서 (OPPOSITION): 두 어머니와 준서에게 괜찮다고 말하지만 진단 뒤 결국 준서를 찾아간다.
- 윤교수 (SECONDARY): 준서에게 고맙다고 말하다 그가 괴롭지 않을 방법을 묻자 시선을 피한다.
- 태석 (SECONDARY): 전시회에 은서를 끌고 와 준서를 자극하고 다음날 가족 소개까지 준비한다.
- 경하 (SECONDARY): 은서를 안고 반대하지 말았어야 했다고 사과하며 부모의 선택을 잘못으로 규정한다.
- 문정 (SECONDARY): (기술 없음)
