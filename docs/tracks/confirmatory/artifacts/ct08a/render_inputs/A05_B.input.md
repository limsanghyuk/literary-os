## 씬 60 — 약혼식 옷을 입은 유미
헤딩: 60 서울 미장원, 오후
의도: 준서가 서울로 돌아와 드레스를 입은 유미를 보고 현재 선택에 다시 합류한다.
core: ROMANCE / BOND
표층: 거울 속 유미와 뒤에 선 준서가 웃으며 한 쌍의 약혼자로 정렬된다.

## 씬 61 — 유미가 준서에게 뿌리내리다
헤딩: 61 서울 약혼식장, 오후
의도: 약혼식에서 유미가 ‘나무’라고 답하며 준서의 은서 기억과 겹치는 상징을 자신의 사랑에 사용한다.
core: ROMANCE / ORACLE
표층: 맞잡은 손 위로 ‘나무’라는 말이 나오고 준서의 표정이 잠시 과거로 흔들린다.

## 씬 62 — 민이 준서의 휴대전화를 줍다
헤딩: 62 호텔 주차장, 오후
의도: 호텔로 돌아온 민이 차에 남은 휴대전화를 발견해 교환실 방문과 은서 대면의 계기를 얻는다.
core: HOOK / INTRO
표층: 빈 조수석에서 울리지 않는 전화기를 든 민이 장난스러운 생각에 멈춘다.

## 씬 63 — 아줌마가 없는 젊은 교환실
헤딩: 63 호텔 로비, 오후
의도: 민이 교환실을 들여다보고 모두 젊다는 말을 들어 자신이 통화한 최씨의 정체를 의심한다.
core: REVELATION / RELIEF
표층: 유리문 너머 또래 직원들만 보이고 민의 표정이 호기심으로 바뀐다.

## 씬 64 — 약혼과 첫 만남이 ‘나무’로 겹치다
헤딩: 64 서울 약혼식장, 오후 / 호텔 ,오후
의도: 민이 최씨가 은서임을 확인하는 동시에 유미가 준서의 첫사랑을 묻고, 준서는 ‘나무’라고 답해 두 관계축을 교차시킨다.
core: HOOK / REVELATION
표층: 교환실의 은서·민과 약혼식의 준서·유미가 분할 화면처럼 겹치며 같은 단어가 서로 다른 의미를 만든다.
