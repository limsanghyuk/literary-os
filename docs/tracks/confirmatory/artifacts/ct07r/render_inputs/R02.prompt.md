# 씬 집필 과제

작품: 38사기동대
회차: 8화
대상 씬 번호: 88
씬 표제: 시장실 (D / 과거)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계

아래는 이 작품의 한 시퀀스에 대한 설계 기록이다. 이 기록이 지금 작성할 씬에 대응하는지는 보장되지 않는다. 대응한다고 판단되는 내용만 사용하라.

[시퀀스 구성] 이 시퀀스는 7개의 씬으로 이루어진다. 작성 대상은 그중 S-6 이다.

[시퀀스 사건]
양정도는 공항에서 실제 마틴킴을 삼진공영 담당자로 속이고, 백성일은 반대편에서 최상준을 상대한다. 두 실제 당사자는 서로 직접 만나지 않은 채 양정도와 백성일을 통해 진짜 계약서·도장·서명을 왕복시키므로 문서 검증은 통과하지만 관계 인식만 조작되고, 그 신뢰를 바탕으로 최상준이 해외 계좌를 요구한다.

[등장 인물과 기능]
- 양정도 (PRIMARY): 문서를 위조하지 않고 진짜 당사자들의 실제 계약서를 거짓 신분 관계 사이로 중계해 검증 가능한 사기를 만든다.
- 백성일 (SECONDARY): 위조 서류가 들킬 위험을 제기한 뒤 정도의 '진짜 서류·틀린 관계' 설계 원리를 이해하고 최상준 쪽 당사자로 행동한다.
- 마틴킴 (SECONDARY): 양정도를 삼진공영 담당자로 믿고 실제 재계약 업무와 서명을 넘긴다.
- 최상준 (SECONDARY): 백성일을 마틴킴 측 연결자로 믿고 실제 서명·도장이 오가는 구조 속에서 해외 계좌까지 요구한다.

[정보 이동]
- 백성일 / LEARN / S-1, S-4, S-6
  이전: 위조 문서라면 기존 계약과 대조해 들킬 것이라고 본다.
  이후: 진짜 문서를 유지하고 당사자 사이의 관계·신분 인식만 오접속시키는 방식이 검증을 통과하는 핵심임을 이해한다.
- 마틴킴 / MISLEAD / S-2, S-3, S-5
  이전: 공항에서 자신을 맞는 양정도의 실제 소속과 역할을 알지 못한다.
  이후: 양정도를 삼진공영의 정식 담당자로 믿고 계약 업무를 맡긴다.
- 최상준 / MISLEAD / S-3, S-7
  이전: 상대 회사의 실제 담당자와 직접 대면하지 않은 상태다.
  이후: 백성일과 양정도를 통해 진짜 서류가 오가자 중개 관계도 진짜라고 믿는다.

[심기와 회수]
- (없음)

[씬별 기능 명제]
- S-1:
  · 백성일이 기존 계약서와의 대조 위험을 제기하게 해 단순 위조가 불가능하다는 설계 제약을 명시한다.
- S-2:
  · 양정도가 실제 마틴킴을 먼저 가로채 거짓 신분 관계를 형성하게 한다.
- S-3:
  · 양쪽 실제 당사자에게 진짜 사업 대화를 병렬로 진행시켜 문서 자체의 진위를 보존한다.
- S-4:
  · 두 당사자가 서로 얼굴을 보지 않는다는 조건을 명시해 관계 오접속이 유지되는 취약점을 설명한다.
- S-5:
  · 마틴킴이 재계약 진행에 동의하게 해 가짜 신분 관계가 실제 업무 권한을 얻도록 한다.
- S-6:
  · 정도가 문서 위조가 아니라 사람의 인식을 바꾸는 사기 원리를 백성일에게 명시해 작전 메커니즘을 고정한다.
- S-7:
  · 실제 도장과 서명을 양쪽에서 받아 왕복시켜 신뢰를 완성하고 최상준이 해외 계좌를 요구하는 다음 행동을 끌어낸다.
