# 씬 집필 과제

작품: 38사기동대
회차: 12화
대상 씬 번호: 61
씬 표제: 양정도 오피스텔 (D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계

아래는 이 작품의 한 시퀀스에 대한 설계 기록이다. 이 기록이 지금 작성할 씬에 대응하는지는 보장되지 않는다. 대응한다고 판단되는 내용만 사용하라.

[시퀀스 구성] 이 시퀀스는 12개의 씬으로 이루어진다. 작성 대상은 그중 S-4 이다.

[시퀀스 사건]
장학주는 장부를 들고 이동하면서 과거 냉동창고에서 팀에 자신이 배신자였고 양정도에게 복수하려 재합류했으며 과거 돈 흐름까지 조작했다고 고백한 순간을 되짚는다. 팀의 분노와 추궁 앞에서 양정도는 변명 없이 사과하고 선택을 맡기며, 장학주는 다미식당 복구와 피해자의 얼굴을 떠올린 끝에 용서는 아니지만 현재 작전을 끝까지 함께하겠다고 결정한다.

[등장 인물과 기능]
- 장학주 (PRIMARY): 과거 양정도에게 속은 복수심으로 팀을 배신했던 사실을 공개하고, 현재 피해자와 동료를 보며 복수와 작전 완수 사이 선택을 다시 한다.
- 조미주 (OPPOSITION): 장학주의 과거 배신이 양정도를 감옥으로 보냈다는 점을 정면 비난해 고백의 도덕적 비용을 높인다.
- 양정도 (SECONDARY): 장학주의 배신을 들은 뒤 변명 대신 사과하고 선택권을 돌려줘 복수의 악순환을 끊을 가능성을 만든다.
- 백성일 (SUPPORT): 팀과 함께 배신 고백을 듣고 현재 계획 누설 여부를 확인해야 하는 공동체의 검증자다.

[정보 이동]
- 팀 / LEARN / S-4, S-5, S-6, S-7, S-8
  이전: 장학주가 과거 함정과 양정도의 수감에 어느 정도 관여했는지 확정적으로 알지 못한다.
  이후: 장학주의 직접 고백을 통해 그가 복수 목적으로 재합류했고 과거 돈 흐름을 만들어 양정도 수감에 기여했다는 사실을 안다.
- 장학주 / RECALL / S-3, S-11
  이전: 차 안에서 현재 배신 행동을 계속하며 팀과 피해자에 대한 경험을 배경화하고 있다.
  이후: 백성일의 질문과 다미식당 복구·피해자 기억을 다시 활성화해 현재 선택의 비교 기준으로 삼는다.

[씬별 기능 명제]
- S-1:
  · 장학주가 장부를 들고 상대편으로 향하게 해 현재 배신 행동과 과거 고백 기억을 긴장 속에 병치한다.
- S-2:
  · 최철우 측이 조상진 사무실까지 장악하게 해 팀 내부 선택과 무관하게 외부 포획이 진행 중임을 유지한다.
- S-3:
  · 백성일의 질문을 회상시켜 장학주가 이미 팀에 진실을 말할 기회를 외면했음을 다시 마주하게 한다.
- S-4:
  · 장학주가 자신이 배신자였음을 팀 앞에 공개해 숨은 갈등을 공동체의 명시적 문제로 바꾼다.
- S-5:
  · 재합류 목적이 피해자 구제가 아니라 개인 복수였다고 인정하게 해 현재 행동의 동기를 정면화한다.
- S-6:
  · 양정도의 과거 기만을 되갚으려 했다는 복수 논리를 설명해 배신의 원인을 드러내되 정당화로 끝내지 않는다.
- S-7:
  · 과거 돈 흐름까지 자신이 만들었다고 폭로해 배신의 실제 피해와 책임 범위를 구체화한다.
