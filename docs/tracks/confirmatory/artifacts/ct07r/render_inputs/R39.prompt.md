# 씬 집필 과제

작품: 38사기동대
회차: 2화
대상 씬 번호: 39
씬 표제: 세무사 대표실 (D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계 (씬카드)

제목: 조상진의 고객 명단
의도: 양정도는 조상진이 탈세를 도운 사업가와 의사, 마진석까지 열거한다. 조상진의 부패가 개별 사건이 아니라 권력자 서비스망임이 드러난다.
핵심 기능: REVELATION / PUNISH
배경: 대표실에서 차분히 이어지는 이름들이 표적의 도망갈 공간을 줄인다.
