# 씬 집필 과제

작품: 38사기동대
회차: 5화
대상 씬 번호: 67
씬 표제: 달리는 양정도 차 안 (D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계

아래는 이 작품의 한 시퀀스에 대한 설계 기록이다. 이 기록이 지금 작성할 씬에 대응하는지는 보장되지 않는다. 대응한다고 판단되는 내용만 사용하라.

[시퀀스 구성] 이 시퀀스는 7개의 씬으로 이루어진다. 작성 대상은 그중 S-4 이다.

[시퀀스 사건]
백성일이 식사를 지연해 시간을 버는 동안 아파트팀은 피싱 경로 설치에 성공하지만 사무실팀은 이미 점검을 받았다는 마진석 동생의 반박으로 발각 직전에 놓인다. 조미주는 때마침 걸려온 양정도의 전화를 '외부에서 점검 착오를 알려온 통화'로 연기해 사과하고 철수함으로써 신분 노출은 피하지만 사무실 설치는 포기한다.

[등장 인물과 기능]
- 조미주 (PRIMARY): 가짜 점검이 들킬 위기에서 양정도의 전화를 외부 착오 확인처럼 연기해 팀을 안전하게 철수시킨다.
- 마진석 동생 (OPPOSITION): 최근 점검 기록을 근거로 미주의 신분을 의심하고 위장을 붕괴시키는 현장 저항이 된다.
- 양정도 (SECONDARY): 집 설치 성공을 확인한 뒤 사무실 진행을 재촉하지만 미주가 발각 직전이라는 정보는 모른다.
- 장학주 (SECONDARY): 마진석 아파트 컴퓨터에는 피싱 경로 설치를 성공시켜 부분 성과를 만든다.
- 정자왕 (SUPPORT): 미주의 점검 위장에 동행하지만 이미 점검을 받았다는 반박에 얼어붙어 현장 위험을 높인다.
- 백성일 (SUPPORT): 식사 자리를 고의로 늘여 침투팀이 작업할 시간을 번다.

[정보 이동]
- 마진석 동생 / MISLEAD / S-2, S-5, S-7
  이전: 미주 일행이 정당한 점검팀인지 의심한다.
  이후: 조미주가 외부 착오 통화를 받은 것처럼 연기하면서 '이미 점검된 곳에 잘못 왔다'는 설명을 믿도록 유도된다.
- 조미주 / INFER / S-5, S-7
  이전: 위장 신분이 기존 점검 기록 때문에 깨진 상태라 즉시 사용할 탈출 설명이 없다.
  이후: 양정도의 전화 타이밍을 외부 착오 확인으로 이용할 수 있다고 판단해 철수용 커버로 전환한다.

[심기와 회수]
- PAYOFF / 38_fake_inspection_escape / S-2, S-5, S-7
  기존 사무실 침투 실패를 우회하기 위해 만든 가짜 점검 방식이 실제 발각 위기에서 철수 수단으로 기능한다.

[씬별 기능 명제]
- S-1:
  · 백성일이 사소한 식사 행동을 늘여 침투팀에 필요한 시간을 더 확보하게 한다.
- S-2:
  · 실제 점검 이력이 위장 신분과 충돌하게 해 사무실 침투를 발각 직전으로 밀어붙인다.
- S-3:
  · 아파트팀의 설치 성공을 확정해 전체 작전이 전면 실패가 아니라 부분 성공임을 만든다.
- S-4:
  · 양정도가 한 현장의 성공을 알고 다른 현장을 재촉하게 해 정보 비대칭을 준비한다.
- S-5:
  · 양정도의 전화가 미주에게 즉흥적인 커버 스토리를 만들 수 있는 외부 신호로 전환되게 한다.
- S-6:
  · 양정도가 현장 노출을 모른 채 결과만 재촉하게 해 통화 양쪽의 정보 차이를 유지한다.
- S-7:
  · 미주가 '점검 착오'를 연기해 신분 노출 없이 철수하되 사무실 설치 실패라는 비용을 남기게 한다.
