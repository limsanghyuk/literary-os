# 씬 집필 과제

작품: 101번째프로포즈
회차: 11화
대상 씬 번호: 51
씬 표제: 우석집 거실(D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계 (씬카드)

제목: 떠나지 못하고 식탁에 앉다
의도: 수정은 가려 하지만 우석과 하영의 만류로 식탁에 앉아 세 사람의 가족 같은 시간을 피하지 못한다.
핵심 기능: BOND / CONFLICT
배경: 우석집 거실·낮
