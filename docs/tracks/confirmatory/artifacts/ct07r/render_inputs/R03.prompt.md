# 씬 집필 과제

작품: 38사기동대
회차: 8화
대상 씬 번호: 88
씬 표제: 시장실 (D / 과거)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계 (씬카드)

제목: 천갑수의 즉시 복종
의도: 과거 천갑수는 방필규 전화를 받자 알아서 처리하겠다고 답하며 조사 중단을 약속한다.
핵심 기능: PUNISH / LOSS
배경: 시장실의 굳은 얼굴이 선택의 비겁함을 보여준다.
