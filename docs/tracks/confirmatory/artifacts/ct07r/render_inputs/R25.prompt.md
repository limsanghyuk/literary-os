# 씬 집필 과제

작품: 101번째프로포즈
회차: 14화
대상 씬 번호: 42
씬 표제: 수정쪽(D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계 (씬카드)

제목: 수정도 떠나는 달재를 보며 울다
의도: 수정은 달재가 사라진 자리에서 자신의 선택과 이별의 현실을 받아들이며 눈물을 흘린다.
핵심 기능: LOSS / BOND
배경: 공원 수정 쪽·낮
