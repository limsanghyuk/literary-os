# 씬 집필 과제

작품: 101번째프로포즈
회차: 14화
대상 씬 번호: 42
씬 표제: 수정쪽(D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계

아래는 이 작품의 한 시퀀스에 대한 설계 기록이다. 이 기록이 지금 작성할 씬에 대응하는지는 보장되지 않는다. 대응한다고 판단되는 내용만 사용하라.

[시퀀스 구성] 이 시퀀스는 3개의 씬으로 이루어진다. 작성 대상은 그중 S-2 이다.

[시퀀스 사건]
공원 이별 직후 수정과 달재가 서로 보이지 않는 위치에서 각각 울고, 달재는 자신이 더 이상 수정을 괴롭히지 않기 위해 사랑을 눈물로 흘려보내는 중이라고 스스로 설명하며 관계를 멈춘다.

[등장 인물과 기능]
- 박달재 (PRIMARY): 수정에게서 물러난 뒤 혼자 울면서 사랑을 포기하는 결정을 실제 감정으로 감당하려 한다.
- 한수정 (SECONDARY): 달재가 사라진 자리에서 자신이 선택한 이별의 현실을 울음으로 받아들인다.

[정보 이동]
- (없음)

[심기와 회수]
- (없음)

[씬별 기능 명제]
- S-1:
  · 달재가 수정의 시야를 벗어난 직후 감정을 무너뜨리게 해 말로 한 이별과 실제 사랑의 차이를 드러낸다.
- S-2:
  · 수정도 별도 공간에서 울게 해 이별이 달재의 일방적 감정이 아니라 상호 상실임을 확인한다.
- S-3:
  · 달재가 울음을 '사랑을 흘려보내는 과정'으로 명명해 이후 돌아가지 않으려는 자기 규율을 굳힌다.
