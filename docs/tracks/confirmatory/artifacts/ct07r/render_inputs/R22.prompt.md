# 씬 집필 과제

작품: 38사기동대
회차: 2화
대상 씬 번호: 39
씬 표제: 세무사 대표실 (D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계

아래는 이 작품의 한 시퀀스에 대한 설계 기록이다. 이 기록이 지금 작성할 씬에 대응하는지는 보장되지 않는다. 대응한다고 판단되는 내용만 사용하라.

[시퀀스 구성] 이 시퀀스는 14개의 씬으로 이루어진다. 작성 대상은 그중 S-7 이다.

[시퀀스 사건]
백성일은 자신에 대한 뇌물 제보와 2과장의 가택수색 밀고를 확인하고 골프장까지 찾아가지만 안국장이 마진석과의 거래로 사과를 강요해 공권력의 유착을 체감한다. 병행해서 양정도는 조상진의 실제 탈세 고객 정보와 실존 직원 검증을 이용해 가짜 국세청 조사 신분을 강화하고 조상진이 뇌물 요구를 스스로 알아듣게 만든다.

[등장 인물과 기능]
- 백성일 (PRIMARY): 뇌물 제보와 내부 밀고를 확인하고 징수 권한의 정당성을 지키려 윗선과 체납자 유착을 직접 대면한다.
- 안국장 (OPPOSITION): 백성일의 비리 제보를 지렛대로 마진석에게 사과하면 문제를 덮어주겠다고 거래하며 조직 권력을 체납자 편에 쓴다.
- 마진석 (OPPOSITION): 내부 밀고와 국장과의 유착을 이용해 백성일의 집행을 징계·가족 협박으로 되갚는다.
- 2과장 (OPPOSITION): 마진석에게 수색 정보를 미리 흘린 내부 협조자로서 백성일의 조직 신뢰를 무너뜨린다.
- 양정도 (SECONDARY): 실제 탈세 자료와 실존 직원 검증을 이용해 국세청 조사관 신분을 믿게 하고 조상진이 스스로 뇌물 협상에 들어오게 한다.
- 조상진 (SECONDARY): 실제 고객 탈세 정보와 직원 확인 때문에 위장 신분을 믿고 조사 회피를 위한 상납 요구로 해석한다.

[정보 이동]
- 조상진 / INFER / S-5, S-7, S-9, S-11, S-13
  이전: 차재원이 실제 국세청 조사관인지 의심하고 조사 목적을 파악하려 한다.
  이후: 실제 직원 존재와 구체 탈세 정보를 검증한 뒤 상대를 조사관으로 믿고, '같이 먹자'는 말을 상납 협상 요구로 추론한다.
- 백성일 / CONFIRM / S-1, S-2, S-3, S-4, S-14
  이전: 수색 정보가 왜 새었는지 의심하지만 내부 유출과 윗선 거래의 구체 구조는 확정하지 못했다.
  이후: 2과장의 밀고 흔적과 안국장·마진석의 거래를 통해 체납자가 시청 내부 보호를 받고 있음을 확인한다.

[씬별 기능 명제]
- S-4:
  · 백성일이 중간관리자 해명 대신 안국장과 직접 충돌하기로 선택하게 한다.
- S-5:
  · 양정도가 실제 탈세 사례를 나열해 위장 신분을 구체 정보로 신뢰시키고 조상진의 공포를 자극한다.
- S-6:
  · 백성일이 골프장으로 이동하며 공식 절차보다 직접 대면을 택한 분노를 행동화한다.
- S-7:
  · 조상진의 고객망을 구체화해 개인 비리가 권력자 대상 조세 회피 서비스망임을 보여준다.
- S-8:
  · 가족 생계용 작은 차로 권력자의 골프장에 진입하게 해 계급 격차 속 직접 대면을 시각화한다.
- S-9:
  · 조상진의 외부 확인 절차까지 통과시켜 양정도의 위장 신분을 단단하게 만든다.
- S-10:
  · 백성일이 필드를 가로질러 권력자 공간으로 직진하게 해 조직적 굴복을 개인적 저항으로 바꾼다.
