# 씬 집필 과제

작품: 101번째프로포즈
회차: 2화
대상 씬 번호: 28
씬 표제: 방송국 근처(N)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계

아래는 이 작품의 한 시퀀스에 대한 설계 기록이다. 이 기록이 지금 작성할 씬에 대응하는지는 보장되지 않는다. 대응한다고 판단되는 내용만 사용하라.

[시퀀스 구성] 이 시퀀스는 5개의 씬으로 이루어진다. 작성 대상은 그중 S-3 이다.

[시퀀스 사건]
현준의 청혼이 찬혁을 잊으라는 요구와 결합해 수정과의 우정을 파열시키고, 직후 찬혁의 사고 기억으로 무너진 수정 앞에 달재가 거짓 신분을 자백하면서 서로 다른 원인의 눈물을 자기 잘못으로 오독한다.

[등장 인물과 기능]
- 한수정 (PRIMARY): 현준의 청혼 압박과 찬혁의 기억 사이에서 관계 경계를 지키고 미해결 애도를 견딘다.
- 이현준 (OPPOSITION): 오랜 우정을 결혼으로 전환하려 하지만 찬혁을 잊으라는 요구로 수정의 상처를 건드린다.
- 박달재 (SECONDARY): 거짓 신분을 자백해 관계를 바로잡으려 하지만 수정의 눈물을 자기 잘못의 결과로 오해한다.
- 박창만 (SUPPORT): 수정이 울었다는 사실을 달재의 연애 진전 신호로 잘못 읽고 행동을 부추긴다.
- 박민재 (SUPPORT): 가족의 오독에 합류해 달재에게 수정과 관계를 밀어붙이라고 압박한다.
- 찬혁 (OFFSCREEN_CAUSAL): 현재에는 부재하지만 사진과 사고 기억으로 수정의 선택을 지배하는 애도 원인으로 작동한다.

[정보 이동]
- 한수정 / RECALL / S-1, S-3
  이전: 찬혁의 죽음은 이미 알고 있으나 현재 대화에서는 기억이 전면화되지 않은 상태
  이후: 현준의 청혼과 이동 경로가 찬혁과 사고의 기억을 현재 감정으로 다시 활성화한다.

[심기와 회수]
- ESCALATION / 101_grief_accident / S-1, S-3
  찬혁의 부재와 사고 기억이 현재 구애를 무너뜨리는 힘으로 다시 작동해 다른 회차의 사고 전모 회수를 준비한다.

[씬별 기능 명제]
- S-1:
  · 현준이 우정을 결혼 제안으로 전환하게 한다.
  · '찬혁을 잊으라'는 압박이 수정의 미해결 애도와 충돌해 관계를 파열시킨다.
- S-2:
  · 달재가 거짓 신분 자백을 준비하고 수정과의 관계를 바로잡으려는 목표를 선행시킨다.
- S-3:
  · 수정의 찬혁·사고 기억을 현재의 붕괴로 재활성화한다.
  · 달재가 원인이 다른 눈물을 자기 거짓말 탓으로 오독하게 해 정보 비대칭을 만든다.
- S-4:
  · 수정의 눈물이라는 제한된 정보가 가족에게 전달되며 다음 오독의 입구가 되게 한다.
- S-5:
  · 가족이 눈물을 연애 진전으로 잘못 해석해 달재의 죄책감과 외부 기대를 충돌시킨다.
