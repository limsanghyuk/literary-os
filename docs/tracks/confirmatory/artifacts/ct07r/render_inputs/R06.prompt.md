# 씬 집필 과제

작품: 38사기동대
회차: 15화
대상 씬 번호: 56
씬 표제: 냉동 창고 (D / 과거)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계 (씬카드)

제목: 뒤통수를 되갚으려 했던 학주
의도: 장학주는 양정도가 자신을 속였던 방식 그대로 갚기 위해 팀에 다시 들어왔다고 말한다.
핵심 기능: REVERSAL / CONFLICT
배경: 동료애로 보였던 복귀가 복수 계획으로 재해석된다.
