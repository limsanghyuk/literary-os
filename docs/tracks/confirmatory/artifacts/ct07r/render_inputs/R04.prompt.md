# 씬 집필 과제

작품: 38사기동대
회차: 5화
대상 씬 번호: 67
씬 표제: 달리는 양정도 차 안 (D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계 (씬카드)

제목: 한 곳 성공, 한 곳 재촉
의도: 정도는 집 설치 성공을 확인하고 즉시 미주에게 연락해 사무실 쪽 진행을 묻는다.
핵심 기능: ESTABLISH / PERIL
배경: 차 안에서 기쁨 없이 다음 위험으로 넘어간다.
