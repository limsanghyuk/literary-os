# 씬 집필 과제

작품: 38사기동대
회차: 12화
대상 씬 번호: 61
씬 표제: 양정도 오피스텔 (D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계 (씬카드)

제목: 당사자들은 서로 얼굴을 못 본다
의도: 양정도는 성일에게 두 기업은 자신들과만 만나기 때문에 진짜 계약이 오가도 상대를 확인하지 못한다고 설명한다.
핵심 기능: REVELATION / HOOK
배경: 중개자의 독점 정보가 사기 성공 조건이 된다.
