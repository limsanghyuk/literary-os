# 씬 집필 과제

작품: 101번째프로포즈
회차: 5화
대상 씬 번호: 34
씬 표제: 벤치가 내려다보이는 고아원 건물 내부(D)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계

아래는 이 작품의 한 시퀀스에 대한 설계 기록이다. 이 기록이 지금 작성할 씬에 대응하는지는 보장되지 않는다. 대응한다고 판단되는 내용만 사용하라.

[시퀀스 구성] 이 시퀀스는 8개의 씬으로 이루어진다. 작성 대상은 그중 S-4 이다.

[시퀀스 사건]
고아원 공사와 촬영이 진행되는 현재에서 철거되는 성당 벤치가 수정의 기억을 자극하고, 찬혁과의 이별 다툼·빗속 재결합·영원 약속·신혼 사고까지 하나의 연쇄 회상으로 복원해 현재 애도의 원인을 구체화한다.

[등장 인물과 기능]
- 한수정 (PRIMARY): 성당 촬영을 버티려 하지만 철거되는 벤치가 찬혁과의 사랑·결혼·사고 기억을 연속으로 되살린다.
- 박창만 (SUPPORT): 은임에게 사과하려다 희극적 말장난으로 중년 관계의 별도 리듬을 만든다.
- 최은임 (SUPPORT): 창만의 사과·치킨 소동을 받아치며 주인공의 비극적 회상과 대비되는 일상 관계선을 유지한다.
- 선자 (SUPPORT): 창만의 행동을 의심하고 경고하며 중년 관계의 코믹한 전조를 연다.

[정보 이동]
- 한수정 / RECALL / S-4, S-5, S-6, S-7, S-8
  이전: 찬혁과 사고를 이미 알고 있으나 현재 촬영에서는 기억의 세부가 배경으로 눌려 있다.
  이후: 벤치라는 장소 자극을 통해 이별 다툼부터 재결합과 사고까지의 연쇄 경험을 현재의 감정으로 재체험한다.

[심기와 회수]
- PAYOFF / 101_grief_accident / S-4, S-5, S-6, S-7, S-8
  초반부터 현재의 구애를 막던 찬혁의 잔상과 미완 애도가 신혼 교통사고의 구체적 기억으로 원인을 드러낸다.

[씬별 기능 명제]
- S-1:
  · 주요 비극선과 대비되는 중년 부부의 소유욕·질투 리듬을 짧게 유지한다.
- S-2:
  · 창만과 은임의 갈등을 사과와 말장난으로 완화해 회상 진입 전 정서 대비를 만든다.
- S-3:
  · 현재의 공사·촬영 진행과 달재의 관찰을 병치해 수정이 과거로 이동할 현실 기준점을 세운다.
- S-4:
  · 철거되는 벤치를 기억 촉발 장치로 사용해 수정의 과거를 현재에 침투시킨다.
- S-5:
  · 니제르 문제를 둘러싼 이별 선언으로 두 사람의 사랑이 갈등과 선택을 통과했음을 보여준다.
- S-6:
  · 수정이 실제 이별을 실행하려 하지만 비와 이동이 재결합 직전의 미완 상태를 만든다.
- S-7:
  · 수정의 귀환과 '기다리겠다'는 약속으로 두 사람의 결합을 다시 확정한다.
