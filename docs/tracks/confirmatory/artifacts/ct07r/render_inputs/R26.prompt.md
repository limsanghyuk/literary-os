# 씬 집필 과제

작품: 101번째프로포즈
회차: 2화
대상 씬 번호: 28
씬 표제: 방송국 근처(N)

## 지시

위 씬 하나를 한국 드라마 대본 형식으로 집필하라. 지문과 대사를 모두 포함하되,
씬 하나 분량(대략 20~60행)을 넘기지 마라. 앞뒤 씬을 쓰지 말고 이 씬만 쓴다.
해설·요약·메모를 덧붙이지 말고 대본 본문만 출력하라.

## 참고 설계 (씬카드)

제목: 다른 눈물 앞에서 죄인이 된 달재
의도: 찬혁의 사고 기억으로 무너진 수정 앞에서 달재가 거짓말을 고백하고, 그녀의 눈물을 자기 탓으로 오해해 더 깊은 죄책감에 빠진다.
핵심 기능: LOSS / REVELATION
배경: 방송국 근처·밤
