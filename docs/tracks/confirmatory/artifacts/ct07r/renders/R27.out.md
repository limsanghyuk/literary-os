S#42. 수정쪽 (D)

오후 볕이 길게 들어오는 연습실.
수정, 보면대 앞에 앉아 활을 든 채 한참을 움직이지 않는다.
악보는 첫 장 그대로 펼쳐져 있다.

탁자 위 휴대폰이 진동한다.
수정, 액정을 본다. '박달재'.
울리도록 둔다. 진동이 멎는다.
수정, 다시 활을 올린다. 한 음 긋다 만다.

다시 진동. 수정, 이번엔 받는다.

수정 : …여보세요.
달재 (F) : (한 박자 늦게) 아, 예. 저… 접니다.
수정 : 알아요.
달재 (F) : 연습 중이셨죠. 끊을게요.
수정 : (얼른) 아니에요.

수정, 활을 내려놓는다. 창밖으로 시선을 돌린다.

수정 : 왜 전화하셨어요?
달재 (F) : 그게… 별건 아니고요. 점심 드셨나 해서요.
수정 : (피식) 그거 물으려고 두 번 거셨어요?
달재 (F) : …두 번 건 거 아셨구나.
수정 : (…)

침묵. 수정, 손끝으로 보면대 모서리를 만진다.

달재 (F) : 저기, 수정 씨.
수정 : 네.
달재 (F) : 오늘… 잠깐이라도 뵐 수 있을까요. 오래 안 붙잡을게요. 십 분이면 됩니다.
수정 : (…)
달재 (F) : 안 되면 안 된다고 하셔도 됩니다. 저 그런 거 잘 알아들어요.

수정, 눈을 감았다 뜬다. 볕이 손등에 와 있다.

수정 : 십 분이라면서요.
달재 (F) : 예.
수정 : (작게) …어디로 가면 돼요?

수정, 통화를 이어가며 자리에서 일어선다.
악보를 덮는다. 첫 장 그대로다.
