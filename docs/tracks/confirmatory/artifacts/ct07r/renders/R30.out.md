S#39. 집 근처 공원 (저녁 즈음)

해가 낮게 걸린 동네 공원.
미끄럼틀 하나, 벤치 몇 개. 아이들은 거의 다 돌아가고 없다.
수정, 하영의 손을 잡고 걷는다. 하영의 다른 손엔 다 녹은 아이스크림.

하영 : 여기서부턴 저 혼자 갈 수 있어요.
수정 : 저기 보이는 데까지만.
하영 : 아빠가 모르는 사람 따라가지 말랬는데.
수정 : (웃으며) 그럼 나 여기 두고 가.
하영 : (잡은 손 안 놓는다) …아니에요.

두 사람, 벤치 앞에서 잠깐 멈춘다. 하영, 아이스크림을 마저 핥는다.

수정 : 엄마 걱정하시겠다. 늦었는데.
하영 : (아무렇지 않게) 엄마 없어요.
수정 : (…)
하영 : 아, 없는 건 아니고요. 이혼했어요. 작년에.
수정 : ……
하영 : 엄마는 캐나다 갔어요. 저는 아빠랑 살고요.

수정, 뭐라 말해야 할지 몰라 하영을 본다.
하영은 남의 얘기하듯 담담하다. 그게 더 마음에 걸린다.

수정 : (조심스럽게) …아빠랑 둘이서?
하영 : 네. 아빠가 요리 되게 못해요. 계란말이도 다 부서져요.
수정 : (웃음) 그래?
하영 : 근데 맨날 계란말이만 해줘요. 그거밖에 할 줄 몰라서.

하영, 나무 막대를 쓰레기통에 넣고 손을 툭툭 턴다.
수정, 손수건을 꺼내 하영의 입가를 닦아준다.
하영, 가만히 서서 닦인다. 그러다 불쑥.

하영 : 아줌마는 왜 저한테 잘해줘요?
수정 : (손 멈추고) …글쎄. 그냥.
하영 : 그냥이 어딨어요.
수정 : (잠시 보다가) 그냥이 제일 많아, 세상엔.

가로등이 하나둘 켜진다.
하영, 골목 안쪽 낡은 빌라를 가리킨다.

하영 : 저기가 우리 집이에요. 삼 층.
수정 : 그럼 이제 들어가.
하영 : (수정의 손을 잡아끌며) 아줌마도요.
수정 : 어? 아니, 나는—
하영 : 잠깐만요. 진짜 잠깐만.

하영, 대답을 듣기도 전에 앞장서서 걷는다.
수정, 끌려가듯 두어 걸음 따라가다 멈춘다.
빌라 삼 층, 불 꺼진 창을 올려다본다.

수정 : (혼잣말) …잠깐만이라니까.

수정, 결국 그 손을 놓지 못하고 골목 안으로 들어선다.
