S#28. 방송국 근처 (N)

방송국 정문에서 큰길로 이어지는 인도.
생방송이 끝난 시간. 스태프 몇이 담배를 물고 흩어진다.
수정, 첼로 케이스를 메고 걷는다. 반 발짝 뒤에서 달재가 종종걸음으로 따라붙는다.

달재 : 수정 씨.
수정 : (걸음 멈추지 않고) 네.
달재 : 저… 오늘 꼭 드릴 말씀이 있어서요.
수정 : 내일 하시면 안 돼요? 제가 지금 좀…
달재 : 내일 하면… 못 할 것 같아서요.

수정, 멈춰 선다. 돌아본다.
달재, 주머니에서 명함 한 장을 꺼낸다. 모서리가 접혀 있다.

달재 : 이거… 제 거 아닙니다.
수정 : 네?
달재 : 처음 뵀을 때 드린 명함이요. 그거 저희 회사 이사님 겁니다. 저 기획실장 아니고요. (숨) 자재 창고 관리합니다. 계약직이고요.
수정 : (…)
달재 : 차도 회사 차였고, 그 아파트도 형네 집입니다. 죄송합니다. 처음에 말씀드렸어야 했는데, 한 번 때를 놓치니까 그다음부턴 더 못 하겠더라고요.

그때 큰길 쪽에서 급브레이크 소리. 이어 길게 울리는 클랙슨.
수정의 어깨가 크게 튄다. 그대로 얼어붙는다.
소리가 멀어져도 수정은 움직이지 않는다.

달재 : (그제야 돌아보고) …수정 씨?

수정, 천천히 고개를 숙인다.
케이스 끈을 쥔 손끝이 하얗게 떨린다.

수정 : (혼잣말처럼) 그날도… 이 소리였어요.
달재 : 예?
수정 : (대답 대신 고개를 젓는다)

수정의 눈에서 눈물이 떨어진다. 소리 없이.
달재, 손을 들었다가 도로 내린다.

달재 : (다급하게) 아, 저… 울지 마세요. 제가, 제가 진짜 죽일 놈입니다.
수정 : (…)
달재 : 속일 생각은 없었는데, 아니 속인 게 맞는데… 그게 이렇게까지 상처가 될 줄은 제가 몰라서.
수정 : (고개 저으며) 아니에요.
달재 : 아닌 게 아니죠. 제가 사람 하나 우습게 만든 건데.

수정, 손등으로 눈가를 훔친다. 억지로 웃어 보인다.

수정 : 먼저 갈게요.
달재 : 수정 씨—
수정 : (돌아서며) 미안해요. 오늘은… 아무 말도 못 듣겠어요.

수정, 빠르게 걸어간다.
달재, 그 자리에 남아 명함을 내려다본다.
접힌 자리를 두 손으로 꾹 눌러 편다. 펴지지 않는다.

달재 : (혼잣말) …그러게. 애초에 하질 말았어야지.

멀어지는 수정의 등. 달재, 끝내 고개를 들지 못한다.
