# CT-11B 사전등록 — 2단 구성 설계(개수 추정 → 경계 결정) (2026-08-17, 생성 전 고정)

**문서 ID**: LOS-CT11B-PREREG-V1.0 · 상위: CT-11 결과(82e2fb3) §5-1 · 개발자 지시(08-17) "다음 실험 진행".
**CT-11이 남긴 질문**: 실패의 원인이 **"몇 개로 나눌지 모른다"**인가 **"어디서 끊을지 모른다"**인가. CT-11에서 |Δk|가 A/B/N 3.22 vs U 1.22였고 교차검색만 1.67로 교정했다. 본 실험은 두 능력을 **분해**한다.

## 1. 팔 (생성 2팔 + 결정론 기준선 2팔)
| 팔 | 정의 | 생성 |
|---|---|---|
| **U** | 균등분할, k=round(n/7.2) — 정보 0 기준선 | 없음 |
| **Uk** | 균등분할, **k=정답**(오라클) — "개수만 알면 등분으로 얼마나 되는가" | 없음 |
| **S1** | **2단 자율**: ①검색20으로 k 추정 → ②추정 k로 경계 결정(두 번 호출, 1단 산출을 2단 입력으로) | 2회/회차 |
| **S2** | **오라클-k 경계**: k=정답을 주고 경계만 결정 | 1회/회차 |
- **검색20**: 대상 작품 **전 회차 제외** 후, `episode_function` 문자 3-gram 자카드 상위 **20회차**를 기능 유사 사례로 제공(각 사례의 총 씬수·시퀀스수·k/n 비율·경계 위치 비율). CT-11의 5건 씬수 근접 검색을 **기능 유사도 20건**으로 강화.
- 회차 설계층은 S1·S2 모두에 제공(누출 5필드 제거: sequence_count·scene_count·seq_span·turning_point.seq_index·core_dist).

## 2. 표본
**4작 × 3회차 = 12회차**: 모래시계·도깨비·뉴하트(CT-11 동일 3작, 신규 회차 EP03·05·07) + **녹두꽃(사극 신규)** EP02·04·06. 생성 36회 호출.

## 3. 종점·임계 (사전 고정, 전량 결정론)
1차 종점 = 내부 경계 **F1(±1)**. 보조: F1(정확), |Δk|, IoU.
| # | 판정 | 임계 |
|---|---|---|
| 1 | **주판정**: S1 − U | **≥ +0.10** (정보 0 기준선 돌파) |
| 2 | **위치 능력 분해**: S2 − Uk | **≥ +0.05** (개수를 알 때 등분보다 잘 끊는가) |
| 3 | **개수 능력 분해**: S1의 \|Δk\| | **≤ 1.22**(CT-11 U 수준 이하) |
| 4 | 2단 효과: S1 − (CT-11 C 평균 0.471) | 참고 보고(표본 상이, 판정 불사용) |
민감도 의무: 작품별 분해(한 작품만 통과 시 ★보류), 최대 기여 1작 제외 재계산, 등간격 작품(도깨비형) 여부 병기.
유효성 게이트: 형식 준수(단조·범위·중복 없음) 36/36, 미달 시 1회 재생성 후 결측 공시.

## 4. 해석 규칙 (사전 고정)
- 1 충족 → 회차 구성 자율 설계 **성립(1차)**.
- 1 미달 + 2 충족 → **"위치는 되나 개수가 병목"** → 처방: k 추정기를 결정론 회귀(장르·씬수·러닝타임)로 대체.
- 1 미달 + 2 미달 + 3 충족 → **"개수는 되나 위치가 병목"** → 처방: 회차층에 막 전환 근거 필드 신설(CT-11 §5-2).
- 전부 미달 → 현행 층으로 회차 구성 불가 확정 → 스키마 보강 없이는 재시도 금지.
