# CT-10 실험 계획 — 전방생성 확증 (2026-08-14, 집 제안 / 개발자 승인 대기)

**문서 ID**: LOS-CT10-PLAN-V1.0 · 근거: GPT 블라인드 전방생성 실험(8/11, PASS_WITH_LIMITATIONS) 정밀 조사 + 우리 CT-01~08 계열 교훈 + 개발자 지시(08-14) "다음 계획 논의".
**성격**: 계획서(사전등록 아님). 승인 후 CT-10 PREREG로 승격하며, 그 시점에 표본·임계·시드를 봉인한다.

## 1. GPT 실험에서 확인한 것 (정밀 조사 결과)
**설계 강점 4가지 — 계승한다.** ①미래 회차 파일 **물리적 배제** + `blind_forward_guard.py`가 참조 필드(ref/path/source)만 스캔하고 자연어 지시문은 제외하는 정교한 누출 검사(위반 0 재확인) ②`SequencePlanCandidate`는 **비정본**으로 격리, Canonical Memory 자동 기입 금지 ③생성 런타임의 provenance를 `PLAN_REF/PLANNER_REF`로 강제 — **원본 SOURCE 사칭 금지**(실제로 1차 런타임이 공식 R8 스키마에서 FAIL: `info_context[].scene_nos/evidence_refs` 누락 3레코드 → 수리 후 PASS) ④크리틱→개정의 정량 효과(77→86, 세부 항목 7축; 지적 사유가 "효율/통계 어휘 반복·감정 과다직진·근거 없는 수치(카페인 74mg)"로 구체적).
**결과의 실체.** 공주가돌아왔다 절제: A 65 / B 84 / **C 88**(축별 분해 확인 — C는 thread coverage 17/20로 최고이나 **episode_selectivity 10/15로 A(11)보다 낮음** = 과다 편성). 결혼못하는남자 루프: 후보 8→선택 6(가족 결혼압박·자기인식 2건 보류), 계획 86, 홀드아웃 호환 **73/100**(중심갈등 예측 10/20, 스레드 선택 10/15가 실점 — 실제 EP09의 부모 결혼공작·혜자 수술·강제여행을 놓침).
**한계(우리 기준 추가).** ①표본 2작·평가 1회 ②채점자=생성자와 동일 모델 계열, 우리 비자명 일치 규약(D-53/54) 미적용 → **스크리닝 등급** ③절제가 사후(post-hoc) 선언 ④네거티브 컨트롤 부재 — "그럴듯한 가짜 계획"을 넣었을 때도 홀드아웃 호환 73이 나오는지 미시험. **④가 가장 큰 공백이다**(CT-01의 N조건이 우리 트랙에서 결정적이었던 것과 같은 이유).

## 2. CT-10 설계 (3팔 × 신규 3작 × 3회차 롤아웃)
**질문**: 분석층(THICK+PlannerInput)이 **앞으로 쓰는 일**에 기여하는가, 그리고 그 기여가 **누적 3회차**까지 유지되는가.
- **팔**: **B**(Stage01–04만) / **C**(+THICK+PlannerInput) / **N**(네거티브: 같은 작품의 **다른 회차** THICK/PlannerInput을 정합한 형식으로 주입 — 형식·분량 동일, 내용만 불일치). N의 역할: "구조화된 문서를 더 준 효과"와 "그 회차에 대한 우리 저작 내용"을 분리.
- **표본**: 구조가 다른 신규 3작(권고: 사극/수사 1 = 돌아온일지매 또는 녹두꽃, 의학/직업물 1 = 뉴하트 또는 닥터챔프, 판타지/로맨스 1 = 도깨비 또는 궁). cutoff=전체의 절반 지점, target=cutoff+1.
- **롤아웃**: 각 작품 **3회차 연속** 생성. 2·3회차는 **직전 생성분으로부터 상태 재계산**(원본 미래 사용 금지 — GPT가 지정한 다음 게이트). 회차마다 blind guard 재실행.
- **채점**: 홀드아웃 호환(1차 종점)은 **범주 고정 요소표 + v2 요소 문법**(subs/fail_if/role_swap)으로 재작성해 3인 블라인드+조정자. **비자명 일치 게이트(평균≥0.80, 최저쌍≥0.75)** 적용 — 미달 시 판정 불선언(우리 트랙 규율 그대로).

## 3. 사전 고정 예정 지표·임계 (승인 후 봉인)
| 종점 | 정의 | 임계 |
|---|---|---|
| 1차: 홀드아웃 호환 | 요소 매칭률 기반 0–100 | **C−N ≥ 10** (내용 조향 분리) **AND** C−B ≥ 3 |
| 2차: 선택 정확도 | 실제 회차 주축 스레드 적중/편성 스레드 | 보조 진단(선택기 개선 표적) |
| 하드 게이트 | 미래 누출 0 · 스키마 PASS · 개정 후 하드 연속성 위반 0 | 전부 필수 |
| 롤아웃 감쇠 | 3회차 호환 − 1회차 호환 | **≥ −15**(붕괴 감지, 하방 명시) |
- 민감도 의무: 작품별 분해(한 작품만 통과 시 ★보류)·최대 기여 1작 제외 재계산. r>1 등 이상치 처리는 C1 준용.
- **모델 분리**: 생성기 = GPT-5 계열(회사, 크레딧 필요) / 렌더·채점 = Claude 계열(집) — 자기채점 교락 제거. 이것이 GPT 실험 대비 가장 큰 방법론 개선이다.

## 4. 집행 분담·비용·순서
1. **선행(회사)**: CT-08B 종결(안A/안B) — 계측기가 열려야 CT-10 채점이 유효. 편입 게이트에 **깊이 항 + provenance 항** 추가(생성 런타임의 SOURCE 사칭 차단 — GPT 실험이 실증한 결함 유형).
2. **CT-10 단계 1(집)**: 정답표 저작 — 3작×3회차 = 9개 타깃 회차의 "주축 요소표"(범주 5×10요소, v2 문법). 원문 정독 격리 저작자. **생성 이전에 완료·봉인**.
3. **단계 2(회사)**: 블라인드 입력 구성 + guard + 3팔 생성(계획→선택기→런타임→씬). GPT 도구(blind_forward_guard.py·validate_generation_loop.py) 그대로 재사용.
4. **단계 3(집)**: 렌더·블라인드 채점·조정·판정·보고. 예상 비용 API $30–50, 소요 2–3일(병렬).

## 5. 이 실험이 답하는 것 / 답하지 않는 것
답한다: 분석층이 **앞으로 쓰는 능력**에 기여하는가(N 대조로 내용 귀속 확인), 그 기여가 **누적 회차에서 유지되는가**, 선택기의 실패 양식은 무엇인가.
답하지 않는다: 작법 품질·인간 필적(CT-03 계열 몫, FAIL 상태 불변) · 전체 시즌 생성 · 사전학습 잠재지식의 완전 배제(단, 생성기와 채점자를 다른 계열로 분리해 **자기채점 교락은 제거**).
