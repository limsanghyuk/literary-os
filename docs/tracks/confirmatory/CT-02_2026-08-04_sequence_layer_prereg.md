## 0. 이 실험이 오늘 아침 실험과 다른 점 — 기저선이 강하다

아침 실험의 기저선 A는 **아무것도 안 준 조건**이었다. 이기는 것이 어렵지 않았고,
실제로 A는 96개 사실요소 중 0개를 재현했다.

본 실험의 기저선 A′는 **오늘 아침에 이긴 그 씬층을 전부 받는다.** 시퀀스에 속한
모든 씬의 SceneBlueprint를 준다. 따라서 이 실험이 묻는 것은 단 하나다.

> **씬층을 이미 다 준 상태에서, 시퀀스층은 무엇을 더 하는가?**

이것은 훨씬 가혹한 질문이고, **FAIL이 나올 확률이 실질적으로 높다.**
미리 인정하고 시작한다. FAIL의 귀결도 미리 못박는다 —
`2026-07-04_DESIGN-4LAYER-REVERSE-FILL-v1.md` §5에 따라 **시퀀스층
(`authored_seq/` 1,724파일 · 93작) DROP 또는 재설계**이며, 이 문서를 쓰는 시점에
그 규칙을 완화할 의사가 없음을 명시한다.

## 1. 검정 가설

**H1 (증분 효용):** 씬층을 모두 받은 렌더러에 시퀀스층을 추가로 주면,
시퀀스의 **거시 구조**(목표–장애–가치이동–전환점)를 원문에 가깝게 재현한다.

**H0:** 차이가 없다. = 시퀀스층은 씬층이 이미 담고 있는 정보의 재기술일 뿐이다.

**H2 (특이성):** 우위가 있다면 *올바른* 시퀀스층 때문이지 *어떤* 거시 텍스트를
더 준 것 때문이 아니다.

H2를 위한 네거티브 컨트롤은 필수다. 오늘 아침 실험에서 판정의 전부는 이 대조군이었다.

## 2. 조건 3갈래

세 조건 모두 렌더러는 **원문을 열람하지 않는다.** 조건 간 정보 격리.

| 조건 | 입력 |
|---|---|
| **A′ 씬층만** | 로그라인 + 회차 위치 + 시퀀스 소속 **전 씬의 SceneBlueprint**(heading·title·intent_gist·core/core2·skin) + 씬별 목표 분량 |
| **B′ 씬층+시퀀스층** | A′ 전부 + 해당 **SeqBlueprint**(sequence_intent·goal·obstacle·value_shift·turn_type·scene_budget·runtime_share·pov_char·place_cluster) + 직전 시퀀스의 sequence_intent |
| **N′ 불일치 대조** | A′ 전부 + **같은 회차 다른 시퀀스**의 SeqBlueprint (필드 동일·분량 동급) |

씬별 목표 분량은 세 조건에 공통으로 원문 자수를 준다(밀도축 교란 제거).
**주의:** 이 공통 고정은 시퀀스층의 예산 캐스케이드 기능을 *유리하지 않게* 만든다.
분량 배분은 그래서 1차 종점이 아니라 2차 종점으로 둔다.

N′ 짝짓기 규칙: 회차 전체 시퀀스 목록에서 `(index + len//2) % len`. 결정론적·사전 고정.

## 4. 종점과 측정

**1차 종점 — 시퀀스 거시충실 (0~5).**
원문(해당 시퀀스 전 씬)만 열람한 별도 추출자가 시퀀스별로 거시 요소 목록을 만든다.
요소 범주는 사전 고정한다:

1. 시퀀스의 목표(누가 무엇을 얻으려 하는가)
2. 주된 장애(무엇이 막는가)
3. 가치 이동 — 시작 상태
4. 가치 이동 — 종료 상태
5. 전환점의 내용(무엇이 뒤집히는가)
6. 전환점의 위치(시퀀스 내 몇 번째 씬인가)
7. 시퀀스 종료 시점의 정보 상태 변화(누가 무엇을 새로 알게 되는가)
8. 씬 간 인과 연결 2~3건(앞 씬의 무엇이 뒤 씬의 무엇을 일으키는가)

채점자는 초고에서 각 요소의 재현 여부를 세고 `5 × 재현수 / 요소수`로 환산한다.

**2차 종점**
- 씬 단위 사실충실 0~5 (오늘 아침과 동일 방식) — 씬층이 공통이므로 조건 간 차이가
  작을 것으로 예상. B′가 여기서도 오르면 부가 소득.
- 환각 건수 — 원문·설계도 어디에도 없는 사건/인물/장치
- **분량 배분 오차** — 씬별 생성 자수 비율 벡터와 원문 비율 벡터의 L1 거리 (코드 계산)
- 씬 수 준수 — 요구된 씬 수를 지켰는가 (코드 계산)
- 전환점 위치 일치 — 0/1 (채점자 판정)

## 5. 판정 규칙 (임계값 사전 고정)

1차 종점(시퀀스 거시충실) 평균에 대해:

- **PASS (시퀀스층 유지·소비자 착수):** `B′ − A′ ≥ 0.5` **그리고** `B′ − N′ ≥ 0.5`
- **FAIL (시퀀스층 DROP/재설계):** `B′ − A′ < 0.5`
- **★무효 판정:** `B′ − A′ ≥ 0.5` 이지만 `B′ − N′ < 0.5`
  → 우위의 정체는 시퀀스층이 아니라 "거시 텍스트를 더 넣은 것". 층 확장 즉시 중단.

Δ ≥ 0.5 는 원설계 G1 임계값을 그대로 승계한다(자의적 완화 금지).

1. 렌더러 = Sonnet 서브에이전트. 조건별·작품별 독립 호출. 원문 미열람, 타조건 미열람.
2. 산출물은 조건 라벨 제거·시퀀스 내 순서 무작위화·무작위 ID 재명명. 매핑은 봉인.
3. 채점자 = 별도 서브에이전트. 원문 + 거시요소 정답표 + 블라인드 초고만 받는다.
   조건 수·조건 정체를 알리지 않는다.
4. 채점 확정 후에만 매핑을 개봉한다.

## 7. 이 실험이 할 수 없는 것 (선언)

- n=12 스크리닝. 작은 효과는 놓친다.
- 2작·1회차뿐. 장르 일반화 불가.
- 회차 1개 안의 시퀀스만 본다. **회차 간 연결(100화 일관성)은 여전히 미측정.**
- 채점자가 LLM이다. 정답표 대조로 부분 완화할 뿐 제거 못한다.
- B′는 **사람이 저작한** 시퀀스층이다. 자기생성(B″)은 별개 실험(계획 §6-4).
