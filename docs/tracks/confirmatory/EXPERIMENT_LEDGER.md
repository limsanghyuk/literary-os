## 3. CT-02 — 시퀀스층, FAIL

**기저선이 강하다는 점이 CT-01과 다르다.** A′는 시퀀스 소속 전 씬의 SceneBlueprint를 전부 받는다.
질문: *씬층을 이미 다 준 상태에서 시퀀스층은 무엇을 더 하는가.*
홀드아웃 12시퀀스 × 3조건 = 36본. 고정 8범주 120요소.

| 지표 | A′ 씬층만 | **B′ 씬층+시퀀스층** | N′ 불일치 |
|---|---:|---:|---:|
| 거시충실 0–5 (1차) | 3.667 | **3.917** | 3.750 |
| 환각 (합) | 75 | 78 | 73 |
| 분량 L1 | 0.151 | 0.160 | 0.150 |
| 씬수 준수 | 11/12 | 12/12 | 11/12 |

Δ(B′−A′) = **+0.250** CI[−0.125, +0.667] 양수4 음수3 동점5 p=1.00 → **임계 0.5 미달, FAIL**
Δ(B′−N′) = +0.167 CI[−0.167, +0.625] p=1.00

**민감도.** 유일한 큰 양수 한성 S05(+2.00)를 빼면 나머지 11개 Δ = **+0.09**. 신호 전체가 1시퀀스 산물.
**작품별.** 건빵 A′ 4.33 / B′ 4.50 / **N′ 4.58(최고)** · 한성 A′ 3.00 / B′ 3.33 / N′ 2.92.
**범주별.** B′가 앞선 것은 전환점내용(+0.17)·인과연결(+0.14) 둘뿐.
**시퀀스층이 담당한다던 goal·obstacle·value_shift 3항목에서 전부 못 이겼다.**

### 기전 3가지

1. **씬층이 이미 거시구조를 함축한다.** A′ 단독으로 73% 재현.
2. **충돌 시 렌더러는 씬층을 택한다.** N′ 렌더러들이 불일치를 알아채고 씬층 우선을 **자가보고**했다.
   그래서 틀린 시퀀스층이 환각을 **늘리지 못했다**(73 vs 75). CT-01과 정반대다.
   조향력 자체가 없다는 뜻이며, 이것이 FAIL의 진짜 근거다.
3. **못 넘어간 것은 시퀀스층이 아니라 스키마 갭.** 한성 S06·S07의 목표/장애/가치종료가
   조건 무관 6본 전부 0. `plant / payoff / information_reveal` 부재가 다시 확인됐다.

### 결함 공시

`turn_position` 오프바이원(건빵 B군 9본, 상대위치는 정답) — **사후 규칙 변경 거부**, 3조건 대칭.
`한성_S07__D3` 5,026B 절단 — 개봉 결과 **N′ 조건**이었으므로 B′ 부풀림 아님.
n=12 · 채점자 LLM · 봉인 예비 6시퀀스 미열람(FAIL이므로 복제 미실시).

### 결정

**"쓸모없다"가 아니라 "씬층 위에서는 쓸모없다"가 측정된 것이다.** 실제 파이프라인에서
시퀀스층의 소비자는 렌더러가 아니라 **씬층 생성기**이고, 그 방향은 측정하지 않았다.

1. `authored_seq/` **신규 저작·신규작 편입 즉시 중단. 삭제 아닌 동결.**
2. **유예 조건은 단 하나** — 시퀀스층만 주고 **씬층을 생성**시켜 사람 저작 씬층과 비교
   (네거티브 컨트롤 필수). 여기서도 FAIL이면 최종 DROP.
3. 저작 자원 전량을 **스키마 갭**(plant/payoff/information_reveal)으로. 신규작 편입보다 우선.
4. 자기생성 조건은 **씬층에서 먼저**. 씬층만이 증분 입증된 층이다.

## 4. CTX-01 — 인물 집중도 (탐색적)

CT-02의 렌더 36본 + 원작 12본을 화자 단위로 재분석. **사전등록 없음 → 판정 근거 아님.**

| | 화자 수 | 최다화자 점유 |
|---|---:|---:|
| 원작 (H) | 10.42 | 27.9% |
| A′ 씬층만 | 12.17 | 31.2% |
| B′ +시퀀스층 | 12.83 | **33.1%** |
| N′ 불일치 | 12.08 | 31.8% |

Δ집중도(A′−H) = +3.3%p CI[−1.7, +8.4] · (B′−H) = +5.2%p CI[+0.7, +9.5] · (N′−H) = +3.9%p CI[−0.5, +8.8]
Δ집중도(B′−A′) = +1.9%p CI[−0.0, +3.9] · (B′−N′) = +1.2%p CI[−1.3, +3.6]

**읽는 법.** 생성물은 인물을 **적게 쓰지 않는다. 더 많이 쓴다.** 벌어지는 것은 분배로,
최다화자에게 원작보다 3~5%p 더 몰린다. 그러나 **불일치 대조군 N′도 같은 폭으로 몰린다.**
즉 이것은 생성 전반의 성질이지 시퀀스층 특이적 현상이 **아니다.**
B′−N′ CI가 0을 포함하므로 "시퀀스층이 집중을 악화시킨다"는 주장은 **성립하지 않는다.**

**정정 공시.** 2026-08-05 대화 중 구두로 보고한 값(원작 8.7화자/29%, A′ 10.2/33%, B′ 9.6/36%)은
빈도 절사·병합 규약이 고정되지 않은 임시 산출이었다. 위 표가 확정값이며, 특히 화자 수의
A′↔B′ 대소가 뒤집혔다. 확정 스크립트 = `G2CAST_run_20260805/cast_concentration.py`(시드 20260805).

**측정 한계.** 파서 4규칙 + 빈도 2회 이상 절사 + 끝 2자 병합키(2026-07-28 규약).
과병합·연속행 누락 여지가 있고, 원작 쪽이 과소집계되면 격차가 부풀려진다.
**결정적 범위 제한: 이 실험에서 인물은 씬층을 통해 모델에게 주어졌다.**
따라서 "맨바닥에서 이야기를 구성할 때 인물을 몇 명 세우는가"는 여전히 미측정이다.

## 성공의 최종 정의 (개발자 확정, 2026-08-05)
**"원작을 얼마나 되살렸나"가 아니라, 작법의 품질이 인간 작가와 대등 혹은 이상이면 성공이다.**
이에 따라 자(척도)의 위계를 고정한다:
1. **사실충실** = 복원 진단용(원본 있는 시험에서만) — 성공 판정에 사용 금지.
2. **기능충실** = 중간 진단용 — "기계가 설계 사다리를 내려올 수 있는가"(CT-06 등 메커니즘 시험)의 자. 성공 판정이 아니라 누수 지점 지목용.
3. **작법 필적(인간 대비)** = **최종 판정의 자** — CT-03 계열. 블라인드에서 인간 작가의 것과 구별 불가(판별 CI<65%)이고 작법 품질 격차 ≤0.5면 성공. 짜깁기 여부는 묻지 않는다(개발자: "시청자는 창작의 존재론을 묻지 않는다").
단서: LLM 채점자는 매끄러운 문장 편향이 있어 생성물에 유리하게 기운다 — CT-03 계열의 **최종 판정은 인간이 본다**(LLM은 스크리닝만). 이는 아키텍처 정본의 "인간 작가=최종 게이트" 원칙과 일치한다.
