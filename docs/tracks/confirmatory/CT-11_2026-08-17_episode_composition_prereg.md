# CT-11 사전등록 — 회차 구성(시퀀스 경계·개수) 자율 설계 (2026-08-17, 데이터 생성 전 고정)

**문서 ID**: LOS-CT11-PREREG-V1.0 · 근거: 개발자 지시(08-17) "사전등록서 작성하고 실험 진행" · 상위 목적: **회차 시놉시스 자율 설계**의 첫 측정 가능 단면.
**왜 이 실험이 먼저인가**: 우리 트랙의 병목은 LLM 채점자다(CT-08 3연속 판정 실패). 회차 **구성**은 정본에 정답(`authored_seq.member_scene_nos`)이 있어 **채점자 없이 결정론으로** 잴 수 있다. 판정이 막히지 않는 실험을 먼저 집행한다.

## 1. 질문
씬 목록만 주었을 때 시스템이 **"이 회차를 몇 개의 시퀀스로, 어디서 끊을 것인가"**를 사람 작가와 같게 판단하는가. 그리고 ①회차 설계층(episodearc) ②**다른 작품의 구성 사례(교차 검색)**가 그 판단을 개선하는가.

## 2. 팔 (같은 표본·같은 채점, 입력만 상이)
| 팔 | 입력 |
|---|---|
| **U (기준선, 생성 없음)** | 균등분할 — 코퍼스 시퀀스당 씬 중앙값(7.2)으로 k=round(n/7.2) 등분. 정보 0 |
| **A** | 씬 목록(번호·heading·title)만 |
| **B** | A + **해당 회차 설계층**(dramatic_question·episode_function·entry/exit_state·central_conflict_axis·act 이름+beat·turning_point 서술) |
| **C** | B + **교차작품 검색**(대상 작품 **제외**한 나머지 작품에서 유사 씬수 회차 5건의 경계 위치 비율·시퀀스 길이 분포·막 배열) |
| **N (네거티브)** | A + **같은 작품 다른 회차**의 설계층(형식·분량 동일, 내용 불일치) |

**누출 차단(필수)**: episodearc에서 `sequence_count`·`scene_count`·`act_structure[].seq_span`·`turning_point.seq_index`·`core_dist`를 **전부 제거**하고 제공한다(이 5필드가 답을 직접 포함). C의 검색 코퍼스에서 **대상 작품 전 회차 제외**. 생성기는 파일 접근이 없는 API(gemini-2.5-pro)로 호출 — 물리적으로 정본을 읽을 수 없다.

## 3. 표본
구조가 다른 3작 × 3회차 = **9회차**: **모래시계(시대극)·도깨비(판타지로맨스)·뉴하트(의학)**, 각 EP02·04·06. 이전 CT 실험 미사용 작품. 팔 4개 × 9회차 = 36 생성.

## 4. 종점·임계 (사전 고정, 전량 결정론)
- **1차 종점**: 내부 경계 **F1(±1씬 허용)**. 보조: F1(정확 일치), |Δ시퀀스 수|, 구간 IoU.
- **판정**:
  1. **주판정** max(B,C) − U ≥ **+0.10** → "정보가 균등분할을 이긴다"(성립)
  2. 층 기여 B − A ≥ **+0.05**
  3. **교차검색 기여 C − B ≥ +0.05** → 다작품 DB가 구성 판단을 개선한다는 첫 증거
  4. **내용 귀속 B − N ≥ +0.05** → 형식이 아니라 그 회차의 내용이 작동
  2~4는 각각 독립 보고하며 하나가 미달해도 나머지는 유효(주판정만이 성립/불성립을 정한다).
- **민감도(의무)**: 작품별·회차별 분해, 최대 기여 1작 제외 재계산. 한 작품만 통과 시 ★보류(장르 의존).
- **유효성 게이트**: 생성 형식 준수(경계 단조 증가·1..n 범위 내·중복 없음) 36/36. 미달분은 1회 재생성 후 그래도 실패 시 결측 처리하고 공시.

## 5. 이 실험이 답하지 않는 것
회차의 **내용**(무엇을 쓸 것인가)·시퀀스 내부 설계·작법 품질. 경계 일치는 **형식 지표**이며 "좋은 회차"의 증거가 아니다 — 사람과 다르게 끊어도 더 좋을 수 있다. 본 실험은 "사람 작가의 구성 판단을 재현하는가"만 측정한다. 또한 생성기가 학습 단계에서 해당 작품을 봤을 가능성은 배제하지 못한다(단, 4팔 공통 조건이므로 팔 간 비교는 유효).
