# G1 사전등록서 — 임시 스크리닝판 (2026-08-04)

**이 문서는 결과를 보기 전에 작성·고정한다.** 채점 후 어떤 항목도 수정하지 않는다.
수정이 필요하면 정정 이력을 남기고 실험을 재실행한다.

## 0. 왜 지금 이 실험인가

2026-08-02 실측: 시퀀스층은 앵커 1작에서 93작 1,724파일로 확장되었으나
G1 관문(`2026-07-04_DESIGN-4LAYER-REVERSE-FILL-v1.md` §5)은 미집행이다.
2026-06-21 제품전략 문서는 "MVP 1번 과제 = 생성기 확대가 아니라 단순 프롬프트 대비
우위의 측정·증명"이라고 못박았으나 그 측정은 오늘까지 수행되지 않았다.

지금까지 이 프로젝트가 통과한 모든 검사(게이트 95/95 PASS, 불변식 전수 PASS)는
**반증 불가능한 종류**다 — 우리가 만든 규칙을 우리가 지켰다는 뜻일 뿐이다.
본 실험의 목적은 처음으로 "아니오"라고 답할 수 있는 장치를 세우는 것이다.

## 1. 검정 가설

**H1 (효용):** 동일 렌더러에 SeqCard 설계층을 주면, 브리프만 준 경우보다
원본 씬의 구체적 사실(사건·소품·동선·인물행동)을 더 많이 재현한다.

**H0:** 차이가 없다. = 우리가 5년간 저작한 층은 렌더러를 원본 쪽으로 끌어당기지 않는다.

**H2 (특이성 — 이번에 처음 세우는 관문):** 우위가 있다면 그것은 *올바른* 설계층
때문이지 *어떤* 구조화된 텍스트를 더 준 것 때문이 아니다.

H2가 핵심이다. 과거 실험(2026-07-03 수직슬라이스, 2026-07-04 축C 파일럿)은
네거티브 컨트롤이 없어 H2를 시험하지 못했고, 그래서 양성 결과가 나와도
"프롬프트를 길게 쓰면 좋아진다"와 구분되지 않았다.

## 2. 조건 3갈래

렌더러는 세 조건 모두에서 **원본을 열람하지 않는다.** 조건 간 정보 격리.

| 조건 | 입력 |
|---|---|
| **A. 맨 프롬프트** | 작품 로그라인 + 회차 위치 + 직전 씬 헤딩 3개 + 대상 씬 heading + 목표 분량 |
| **B. 작가실(SeqCard)** | A 전부 + 대상 씬의 `title`·`intent_gist`·`core`/`core2`·`skin` + 직전 씬 3개의 intent 연속성 |
| **N. 불일치 대조** | A 전부 + **같은 회차 다른 씬**의 `title`·`intent_gist`·`core`/`core2`·`skin` (토큰량은 B와 동급) |

목표 분량은 세 조건 모두에 원본 글자수를 준다(밀도축은 2026-07-04에 이미
`renderer_prompt_constraints`로 해소된 별개 변수 → 교란 제거 목적으로 공통 고정).

N의 짝짓기 규칙: 대상 씬 i에 대해 같은 회차 정렬통과 씬 중 `(i + len//2) % len` 위치의 씬.
결정론적이며 사전 고정.

## 3. 홀드아웃 (10씬, 2작)

선정 규칙(기계적, 사전 고정): 회차 01 → bp heading과 원문 heading이 정규화 일치하는
씬만 후보 → 원문 200~2,500자 → 잔여 목록에서 균등 간격 5개.

| 작품 | 씬 | 원문 자수 |
|---|---|---|
| 건빵선생과별사탕_01 (2005 학원/코미디) | 1, 7, 10, 15, 19 | 374 / 295 / 1431 / 435 / 520 |
| 한성별곡_01 (2007 사극/미스터리) | 1, 14, 27, 42, 57 | 363 / 692 / 903 / 1530 / 462 |

두 작품 모두 저명도가 낮아 렌더러의 암기 재현 위험이 낮다(교란 통제).

**기록된 한계:** 건빵선생과별사탕은 원문 파서가 s20 이후 번호 정렬에 실패해
정렬통과 씬이 20개뿐이며, 따라서 5개 픽이 회차 전반부에 몰린다. 한성별곡은 회차 전체를 span한다.

## 4. 종점과 측정

**1차 종점 — 사실충실 (0~5).** 원본만 열람한 별도 추출자가 씬별로 구체 사실요소
(사건·소품·공간동선·인물의 구체적 행동) 목록을 먼저 만든다. 채점자는 초고에서
그 요소들의 재현 여부를 세고 비율을 0~5로 환산한다.

**2차 종점**
- 기능충실 0~5 (씬의 극적 기능·인물 특질 재현) — 블라인드 채점
- 환각 건수 — 원본·설계도 어디에도 없는 사건/인물/장치를 창작한 횟수
- 분량 적합 |log₂(생성자수/원문자수)| — 코드 계산
- 인물명 재현율 = 원본 발화 인물 중 초고에 등장한 비율 — 코드 계산

## 5. 판정 규칙 (임계값 사전 고정)

1차 종점 사실충실 평균에 대해:

- **PASS (진행):** `B − A ≥ 0.5` **그리고** `B − N ≥ 0.5`
- **FAIL (층 DROP 검토):** `B − A < 0.5`
- **★ 무효 판정 (가장 위험한 결과):** `B − A ≥ 0.5` 이지만 `B − N < 0.5`
  → 우위의 정체는 SeqCard가 아니라 "프롬프트에 구조화된 텍스트를 더 넣은 것".
  이 경우 우리가 저작한 내용의 가치는 **미입증**이며, 층 확장은 즉시 중단한다.

Δ ≥ 0.5 는 원설계 G1의 임계값을 그대로 승계한다(자의적 완화 금지).

## 6. 블라인드 절차

1. 렌더러 = Sonnet 서브에이전트. 조건별·씬별 독립 호출. 원본 미열람.
2. 산출물은 조건 라벨을 제거하고 무작위 ID로 재명명. 매핑은 파일에 봉인.
3. 채점자 = 별도 서브에이전트. 원본 + 사실요소 정답표 + 블라인드 초고만 받는다.
   조건이 몇 개인지, 어떤 조건이 존재하는지 알리지 않는다.
4. 채점 확정 후에만 매핑을 개봉한다.

렌더러 ≠ 채점자, 채점자는 조건 미지 — 2026-07-04 파일럿이 후퇴했던
"렌더러=심사자=동일 모델 자기평가"를 반복하지 않기 위함이다.

## 7. 이 실험이 할 수 없는 것 (선언)

- n=10은 **스크리닝**이다. 큰 효과나 완전한 무효는 잡아내지만 작은 효과는 놓친다.
  PASS가 나와도 확증이 아니라 "30씬 확증실험을 돌릴 자격"을 얻는 것뿐이다.
- 씬 단위 재현만 본다. 100화 장편 일관성(우리 제품 주장의 본체)은 측정하지 않는다.
- 상업성·시장은 측정하지 않는다.
- 채점자가 LLM이므로 채점자 편향이 잔존한다. 사실요소 정답표를 원본에서 먼저
  뽑아 대조하는 방식으로 부분 완화할 뿐 제거하지 못한다.

## 8. 무엇이 이 실험을 무효로 만드는가

- 세 조건 중 하나라도 원본이 유출되면 무효.
- 렌더러가 해당 작품을 암기 재현하면 무효(A조건 점수 이상 상승으로 탐지).
- 채점자가 조건을 추론해내면 무효(채점 근거 서술에서 사후 점검).
