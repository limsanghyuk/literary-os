## 1. 무엇이 잘못됐나

사전등록 §6은 1차 종점을 "판별 정확도, binary forced choice, **우연 수준 50%**"로 잡고
PASS 조건을 "판별 정확도 95% CI 상한 < 65%"로 규정했다.

그런데 §4의 라틴방격은 채점자 1인에게 **H 8문항 · A′ 8문항 · B′ 8문항**을 준다.
즉 "원작"의 실제 비율은 **1/3**이지 1/2이 아니다.

이 상태에서 단순 정확도를 쓰면, **아무것도 읽지 않고 전부 "생성"이라고 답한 채점자가
정확도 66.7%를 얻는다.** 65% 문턱을 우연히 넘는다. 판정이 뒤집힌다 —
작법이 필적함에도 FAIL이 나온다. 종점 통계량이 설계와 맞지 않았다.

이것은 결과를 보고 발견한 것이 아니다. 문항지를 조립하는 과정에서 발견했고,
채점은 아직 시작되지 않았다.

## 2. 개정

**1차 종점 통계량을 균형정확도(balanced accuracy)로 바꾼다.**

```
BA = ( 원작 문항 정답률 + 생성 문항 정답률 ) / 2
```

균형정확도는 판본 구성비와 무관하게 우연 수준이 정확히 50%다.
전부 "생성"이라 답하면 BA = (0 + 1)/2 = 0.50 — 우연 수준으로 정확히 떨어진다.

**문턱은 그대로 65%를 쓴다.** 즉:

- **PASS(H1 채택, 구분 불가)** = BA의 95% CI **상한 < 65%** **AND** `H − max(A′, B′) ≤ 0.5`
- **FAIL** = BA의 95% CI **하한 ≥ 65%** 또는 작법 품질 격차 > 0.5
- **★보류** = 둘 중 하나만 성립

신뢰구간은 CT-01·CT-02와 동일하게 **부트스트랩 20,000회, seed 20260805**,
재표집 단위는 **문항**(채점자-씬 쌍)으로 한다.

**보정 앵커 4건은 이 통계에서 전량 제외한다.** 앵커는 채점자 자격을 거르는 용도이지
판별 대상이 아니다. 따라서 BA의 분모는 채점자당 24문항, 총 72문항이다.
(앵커를 포함하면 원작 10 / 생성 18이 되지만, 제외 후에는 원작 8 / 생성 16이다.
어느 쪽이든 1/2이 아니므로 균형정확도가 필요하다.)

## 3. 함께 고정하는 분해 지표

균형정확도만으로는 어느 조건이 걸렸는지 알 수 없다. 다음 둘을 **사전에** 고정한다.
둘 다 보조 지표이며, 판정은 위 §2의 BA 하나로만 내린다.

- **BA(H vs B′)** — SeqCard 조건. 이것이 본 트랙의 관심 대상이다.
- **BA(H vs A′)** — 맨프롬프트 조건. B′보다 높아야 정상이다.
  A′가 B′보다 구분하기 **쉽지 않다면**, SeqCard가 작법을 개선한 게 아니라는 뜻이다.

각각 원작 정답률은 공통의 H 문항에서 가져오되, 생성 정답률만 해당 조건 문항으로 계산한다.
H 문항이 두 지표에 중복 기여하므로 **두 지표는 독립이 아니다.** 비교는 서술로만 하고
차이에 검정을 붙이지 않는다.

## 4. 채점자에게는 알리지 않는다

판본 구성비(1/3)는 문항지에 적지 않는다. 알려주면 채점자가 답의 개수를 맞추려 하고,
그것은 작법 판단이 아니라 배분 전략이 된다. 균형정확도가 구성비 문제를 이미 해소하므로
알릴 필요도 없다.
