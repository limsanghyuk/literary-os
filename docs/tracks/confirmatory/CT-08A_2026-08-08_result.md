## 4. 이 기록에서 읽히는 것과 읽히지 않는 것

**읽히는 것 (조건부·비판정)**
- Δ_apparent(0.479) < Δ_true(1.479) 가 세 채점자 전원에서 같은 부호·같은 순서로 나왔다.
  사전등록 §6 이 "필드 단위 절제가 기여를 과소평가한다는 실험 내 직접 증거" 라고 미리 정의한 패턴이다.
  즉 **D-52 재기술 교락은 실재하는 방향으로 관측되었다.** 다만 무효 판정이므로 확정하지 않는다.
- 배치 유효성은 강하다. TN 0.042 는 음성대조가 거의 완전히 0 이고, B−TN 3.25 는 채점이
  실제 내용에 반응했음을 뜻한다. 즉 **일치도 미달은 "채점자가 아무렇게나 찍었다"가 아니다.**

**읽히지 않는 것**
- `scene_notes` 유지 여부. KEEP 도 DROP 도 선언 불가다.
- 따라서 **98작 후판 저작은 여전히 미승인**이다. 작가안 3필드(대가·비합리적 선택·말하지 않은 것)
  즉시 승격도 성립하지 않는다.

3인 만장일치 요소 975 / 1,200 = 0.8125.

일치도는 **점수가 0에 붙은 팔(TN)에서 가장 높고, 중간 점수대 팔(T5)에서 가장 낮다.**
불일치는 팔의 함수가 아니라 **판정이 경계에 걸리는 요소의 함수**로 보인다.
사전등록 §7-3 이 미리 적은 한계("처치가 도구 의존이면 판정도 도구 의존")와 같은 계열의 문제가
채점 쪽에서도 발생한 것이다. 요소 본문의 `불성립:` 절 해석이 채점자마다 갈렸다는 보고가
3인 모두의 자기보고에 공통으로 나타났다 (예: 연출형식을 명시한 불성립 절 vs 상위지침 충돌,
복합 요소의 부분 충족 처리, 역할·주체 역전의 허용 범위).
