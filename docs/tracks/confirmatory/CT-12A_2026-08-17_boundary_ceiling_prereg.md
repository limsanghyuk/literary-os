# CT-12A 사전등록 — 경계 라벨 신뢰도(천장) 측정 (2026-08-17, 주석 생성 전 고정)

**문서 ID**: LOS-CT12A-PREREG-V1.0 · 개발자 지시(08-17) "순서대로 진행" 중 ①.
**왜**: CT-11 계열의 모든 판정은 정본 경계를 정답으로 삼는다. 그런데 **그 정답의 재현성이 한 번도 측정된 적이 없다.** 사람(또는 동급 주석자) 둘이 같은 회차를 나눌 때 얼마나 일치하는지 모르면, 0.76이 천장 근처인지 한참 아래인지 알 수 없다.

## 0. 선행 조사 결과 (본 등록 전 수행·공시)
- 국희 재저작 20쌍: 경계 **100% 동일** — 재저작이 "좌표 불변 계약"(내용 6필드만 수정)을 따르므로 **독립 재분할이 아님**. 천장 추정에 사용 불가.
- V24 구판(2026-08-02) vs 현행 정본 **공통 1,724회차 전수 대조: 경계 상이 0건**.
→ **정본 코퍼스에는 독립 재분할 사례가 존재하지 않는다.** 즉 우리 경계 라벨은 **단일 주석자 산출이며 신뢰도 미검증**이다(신규 결함 등재 대상). 따라서 신규 독립 주석으로 측정한다.

## 1. 설계
- **표본 4회차**(층 혼합): 베토벤바이러스_02·카인과아벨_02(등간격층) / 풍문으로들었소_02·대물_02(불균등층). 전부 CT-11C 표본과 동일 → 기존 수치와 직접 비교 가능.
- **주석자 2인**: 서로 격리된 세션이 **원문 대본 전문만** 읽고 시퀀스 경계를 독립 저작. 정본 seqblueprint·씬카드·회차설계층 접근 금지(정답 비접촉). 지침은 정본 저작 지침과 동일 문구(가치 부호 전환 기준).
- **주석자 성격 공시**: 주석자는 LLM이다. 단 **정본 라벨 자체도 LLM 주석자(gpt-5.6-thinking / sonnet_reading)가 원문 정독으로 저작**한 것이므로, 동일 계열 주석자의 재현성을 재는 것은 **본 코퍼스의 신뢰도 추정으로 타당**하다. 인간 주석자 천장은 별도 과제로 남긴다.

## 2. 종점 (CT-11과 동일 지표, 사전 고정)
- **R1 주석자간 일치** F1(±1): 두 신규 주석자 A·B 사이.
- **R2 정본 재현율** F1(±1): 각 주석자 vs 정본.
- 보조: |Δk|, 정확 일치 F1.

## 3. 해석 규칙 (사전 고정)
| 관측 | 해석 |
|---|---|
| R1 ≥ 0.85 | 경계 라벨은 재현성 높음 → CT-11 계열 판정 **유효**, 결정론 등분 0.76은 천장 아래 → 개선 여지 실재 |
| 0.60 ≤ R1 < 0.85 | 중간 신뢰 → CT-11 판정의 **임계(+0.10)를 R1 기준으로 재조정**해야 함 |
| R1 < 0.60 | **라벨 신뢰도 붕괴** → 경계 일치도를 종점으로 쓰는 모든 실험(CT-11·11B·11C) 판정을 ★유보로 강등하고, 종점을 "경계 일치"에서 다른 지표로 교체 |
| R2 ≪ R1 | 정본이 특이한 방식으로 나뉘었다는 뜻 → 정본 저작 지침 재검토 |
본 실험은 성능 실험이 아니라 **계측기 검정**이다. 어떤 생성 조건의 우열도 주장하지 않는다.
