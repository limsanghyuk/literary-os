# CT-06 정답표 검증 종료 규칙 (v1.2 검증 **착수 전** 고정)

문서 `LOS-CT06-KEY-STOP-V1.0` · 2026-08-05 · 채점 데이터 0건 상태에서 사전 고정

## 왜 필요한가
정답표 개정은 무한 반복될 수 있다. 검증자를 새로 붙일 때마다 새 지적이 나오고,
지적을 고치면 다른 축이 깨진다(v1.0→v1.1 에서 실측: 개정 9요소 통과 3/9 = 0.33,
미개정 41요소 34/41 = 0.83). 개정 라운드를 통과 기준 없이 반복하는 것은
"검증 가능한 작업으로의 도피"이며, 공정 통과를 효용 증거로 착각하게 만든다.

## 사전 고정 판정 (v1.2 3차 독립 검증)
- **집행 가능**: fail 0 **AND** weak ≤ 5 (49요소의 10%)
- **집행 불가**: 위 조건 미달

## 집행 불가일 때의 처분 — 4차 개정 라운드는 없다
추가 개정 대신 다음 둘 중 하나를 **개발자 판단으로** 택한다.
1. **씬당 요소 수 가변 확대** — 5축(씬배치·원문일치·기능충실·독립성·evidence)을
   동시 만족하지 못하는 요소를 삭제하고 그 씬의 `n_elements` 를 낮춘다.
   채점식 `5.0 × matched / n_elements` 는 이미 가변 n 을 지원한다(METHOD.md §4).
   대가: 씬당 요소가 줄면 1요소의 점수 가중이 커져 분산이 확대된다.
2. **1차 종점 자체의 재검토** — 5범주 격자를 짧은 씬에 강제하는 것이 원인이라면
   기능충실 척도가 이 홀드아웃에서 측정 가능한 양인지부터 다시 묻는다.

## 검증자 간 불일치 보고 의무
3차 검증자는 49요소 전부를 판정한다. 그중 v1.2 에서 **손대지 않은 35요소**의 판정을
2차 검증(v1.1)과 대조해 검증자 간 일치율을 산출한다. 개정 품질과 검증자 엄격도를
분리하기 위한 것이며, 일치율이 낮으면 정답표 자체의 신뢰도 문제로 보고한다.
2차 대조 실측: 미개정 41요소에서 1차↔2차 일치 34/41 = 0.829, 불일치 7건 전부
hold→weak 단방향(무작위 잡음 아님).
