## 표본·판정 (원안 유지 + C1~C4 반영)
- 홀드아웃 10씬(정본 DB 실측 일치: 건빵 S01 7·S02 5·S03 6·S04 5 / 한성 S01 9·S02 9·S03 9·S05 10·S07 5 = 65멤버). 카드 생성은 65멤버 전부×2팔, 렌더는 대상 10씬×4팔=40본.
- **1차 종점**: 기능충실 = 5.0×matched/n_elements(씬별), 채점자 3인 중앙값.
- **판정**: r=(B″−A)/(B−A). **r≥0.70 AND (B″−N″)≥1.0 → 성립** / r≤0.30 → 불성립(→C4 행동 4항) / 중간 → 범주별 r 분해로 결론. **C2**: (B″−N″)∈[0.5,1.0) AND r≥0.70 → ★부분 성립(내용 조향 실재·강도 미달). **C1**: r>1.0 → 성립 판정+드리프트 이상 신호 등재. **C3**: 스코프=2작 한정, 코퍼스 일반 주장 금지.
- **민감도(의무)**: ①s7 제외 재계산 ②작품별 r 병기(한 작품만 통과 시 ★보류) ③한성 S05 단독 기여 확인.
- 무효 조건: 렌더러가 원문·DB를 읽은 정황 / 채점자에게 팔 라벨 노출 / 생성 후 패킷 수정.
