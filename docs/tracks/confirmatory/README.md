## 이 트랙이 지금까지 바꾼 것

- 씬층과 시퀀스층 사이에서 **자원 배분이 처음으로 데이터로 갈렸다.**
- `authored_seq/` 신규 저작 중단(동결, 삭제 아님). 유예 조건 1개 명시 = CT-06.
- 저작 자원 1순위를 신규작 편입에서 **스키마 갭**(plant/payoff/information_reveal)으로 이동.
- 사전등록이 없었다면 CT-02의 Δ=+0.250과 "8범주 중 2범주 우세"를 통과로 쓸 수 있었다.
- ★**CT-03 이 실패의 성질을 뒤집었다.** 작법 점수는 생성물이 **더 높은데도**(격차 −0.108) 거의 전부 들킨다. 채점자 사유의 **79.2%가 "너무 정돈돼 있다"**. 못 써서 들키는 것이 아니라 **질서 때문에** 들킨다. 개선 방향이 "더 잘 쓰기"에서 **"불규칙성 재현"**으로 바뀐다.
- ★**CT-07R이 98작 후판 저작을 승인했으나, 승인의 정체가 예상과 다르다.** 전체 r_T 0.817은
  씬내부 0.567(사람 씬카드가 여전히 우위)과 배치관계 1.386(후판이 씬카드를 넘어섬)이 섞인 값이다.
  후판은 씬카드를 **대체**하지 않는다 — 씬카드가 구조적으로 다룰 수 없는 **배치관계 층**을 채운다.
  98작 발주 지시문의 무게중심을 씬 묘사가 아니라 **앞뒤 씬과의 관계**에 두어야 한다는 뜻이다.
- ★**효과 크기는 재현되지 않았다** — CT-07 1.63 대 CT-07R 0.817. 부호와 존재는 재현, 크기는 절반.
  단일 배치 결과를 발주 규모 산정의 근거로 쓰지 않는다.
- ★**LLM 검증·채점의 신뢰 한계가 두 실험에서 같은 형태로 나왔다**(D-34 / D-37). 채점자는 재려는 것을 못 재면 잴 수 있는 것을 잰다. **LLM 통과를 품질 증거로 쓰지 않는다**가 이 트랙의 규칙이 됐다.
