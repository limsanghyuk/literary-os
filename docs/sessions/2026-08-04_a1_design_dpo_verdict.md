## 2. 생성 행동 평가 (A1_EVAL, held 20, greedy·결정론)
- **BASE**: 형식완결 0.820 · **전환유형 일치 0.000 (0/20)** — 학습 전 8B는 작가의 전환 선택을 전혀 재현 못함.
- **LORA**(1차 실행 부분 관측): 형식완결 관측 표본 **1.00**(BASE 0.80 대비 개선 — 설계 5필드를 더 규율 있게 완성), 전환유형 관측 표본 0.0. ※로그가 재실행으로 초기화되어 LORA 요약치는 재실행 완료 시 증보(greedy=결정론이라 수치 동일 재현).

## 3. 정직한 해석 — "학습은 일어났으나, 이긴 곳이 이미 이기던 곳이다"
1. 마진 +57% + 형식완결 개선 = **정책은 움직였다**(더 확신 있게, 더 규율 있게). 그러나 이진 승패는 0.850에서 불변 — 이미 맞히던 85%를 더 확신하게 됐을 뿐, **경계 15%(hard 쌍)를 넘지 못했다.** W 포화 상태에서 마진만 오르는 전형적 패턴.
2. 이 패턴은 기시감이 있다 — **SP-E.10 졸업 트랙이 정확히 같은 벽에서 hardB 커리큘럼(경계 사례 집중)으로 뚫었다**(W 0.58→0.81, 5/5 ADOPT). 검증된 처방이 존재한다.
3. 씬 층위(R1·R2 ΔW+)와의 차이: 설계 층위는 rejected가 너무 쉬웠을 가능성(맥락 불일치·셔플은 base가 이미 85% 변별) — 난이도 사다리 교훈의 재적용 필요.

## 4. A2 라운드 처방 (사전등록 초안)
- **rejected 상향**: 결정론 열화 → **프런티어 생성 설계**(G2' 산출 48건 + 추가 생성 — base가 구별하기 어려운 실전 대조) 및 held 오답 15% 계열 hard 쌍 증식.
- 2에폭 + held 동일 유지(추세 비교) · max_length 896 유지(완주 확인됨: 총 3.5h, 호스트 경합 구간 포함).
- 성공 기준: W1>0.870(CI 하한>0.5) 또는 생성 전환유형 일치 >0(0/20 탈출).

## 5. 라운드의 수확 (ROLLBACK이어도 남는 것)
- 설계 층위 학습 파이프 개통(데이터 빌더·킷 변형판·평가 킷 — 재사용 자산).
- 기준선 확정: 설계 선호 W0=0.850, 생성 전환유형 일치 0/20 — A2의 출발점.
