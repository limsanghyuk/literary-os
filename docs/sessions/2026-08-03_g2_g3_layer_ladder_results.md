## 2. 해석 — 층이 무가치한 것이 아니라, 소비처가 틀린 것
1. 회차·작품 컨텍스트를 씬 프롬프트에 직접 부으면 주의가 분산되고(기능 −0.33), 더 많은 맥락을 담으려다 분량 규율이 무너진다(밀도 −0.50). E3-v4(심층 주입 무효)·v5b(목표 불일치)와 수렴하는 세 번째 실측.
2. 도출되는 설계 법칙 — **인접 층 소비 원칙(Adjacent-Layer Consumption)**: *N층의 소비처는 N−1층의 "설계 단계"이지, N−2층 이하의 "실행 단계"가 아니다.* 작품층은 회차를 설계할 때, 회차층은 시퀀스를 설계할 때, 시퀀스층은 씬을 렌더할 때(G1 입증) 소비되어야 한다. 층을 건너뛴 주입은 역효과. — 7-pass 파이프라인의 각 패스별 입력 계약을 이 원칙으로 고정할 것(P5 씬 루프의 입력 상한=시퀀스층: 방금 승격한 scene_renderer의 스코프가 정답이었음이 실측 확정).
3. 따라서 "회차층이 값하는가"의 **올바른 시험은 2단 파이프**다: G2' = [회차 아크 유/무] → **시퀀스 설계를 생성** → 그 설계로 씬 렌더 → 최종 품질 비교. 회차층의 기여는 자기가 설계하는 층(시퀀스)의 산출을 통해 간접 측정되어야 한다. G3'도 동형(작품층→회차 설계→하류).
