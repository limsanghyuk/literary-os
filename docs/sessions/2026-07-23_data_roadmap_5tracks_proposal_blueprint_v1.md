### §1. 배경 — 갭 진단 5건
1. **기획층 입력 부재**: 코퍼스는 씬→시퀀스→회차→시리즈아크까지 완비했으나 그 위층(로그라인·시놉시스·기획의도·전제)이 없다. "전제→구조" 기획 학습쌍의 입력측이 0건.
2. **구성→산문 쌍 소량**: brief2prose 479쌍(7작)뿐. seqcard 70작과 corpus_ko 원문의 씬 정렬이 안 돼 있어 대량 수확 불가.
3. **정본 협소**: 학습 투입 가능한 CANONICAL 23작 vs PASS_CANDIDATE 46작 대기. v1 스키마(~35작, state_headline 없음)와 v2 이원화.
4. **메타GT 잠정**: 명성 닻(수상·시청률)이 LLM 학습지식 기반 잠정치 — corpus_ko EXP 보고서가 "권위데이터 교체 시 신뢰도 상승" 명기.
5. **시대 일반화·인간 GT 미검증**: 고전 중심 코퍼스의 현대 전이 여부 미측정, 인간 판정 데이터 0건.

- DR-1+DR-2 완료 시 기획(전제→아크)·구성(아크→시퀀스→씬비트)·생성(브리프→산문) **전 층위 학습쌍**이 기존 자산만으로 갖춰진다.

- DR-5의 은닉 시험지는 "고전 연료로 현대 창작 가능"의 실측 판정 장치 — 작품당 고비용 대본을 학습용 다량이 아니라 **시험지 소량**으로 쓰는 것이 원화당 가치 최대.
- Track1 밀도보강(진행 중)·Track2(드롭)와 스코프 충돌 없음. DR-3 심사는 밀도보강 완료 작품부터 후행.

## 제2부 — 설계도 (트랙별 집행 명세)

### §4. DR-1 — PlanningLayer 역생성 (권장: 파일럿 1작 → CANONICAL 23작 → 70작)

**산출 경로**: `seqcard_ko/authored_planning/<작품>.planning.json` (작품당 1파일)

**스키마 `WorkPlanningCard`**:
```json
{
  "schema": "WORK_PLANNING_CARD_V1",
  "work_id": "대장금",
  "logline": "≤90자 1문장 — 주인공·목표·장애·아이러니 포함. ★결말·최종 반전 서술 금지(AM-1)",
  "premise": "what-if 전제 1~2문장. ★사전(pre-hoc) 언어 — 갈등은 있되 해소는 없음(AM-1)",
  "core_conflict": "핵심 갈등(대립축) 1문장 (AM-8)",
  "target_audience": "타깃 시청자 명세 (AM-8)",
  "synopsis_300": "300자 내외 — 사용자 선택 단계용 밀도",
  "synopsis_full": "시리즈 굵은 줄기 3~8문장 (막 구조 표기)",
  "planning_intent": "기획의도 — 이 이야기가 왜/누구에게 (≥40자)",
  "genre": ["사극","성장"], 
  "format": {"episodes": 54, "era_bucket": "2000s", "form": "지상파장편"},
  "evidence": {"fullseries_arc_ref": true, "key_scene_refs": ["대장금_01#1", "..."] },
  "by": "claude-opus / planning-reverse 2026-07-XX"
}
```
**반게이밍 규칙 (v2 방법론 §7과 동일 무게)**:
- `key_scene_refs` ≥3, 전부 실재 scene_no여야 함(게이트가 SceneCard 대조 검증).
- `planning_intent`는 **텍스트 내 근거만** — 학습지식(실제 제작사 비화·시청률 후일담) 유입 금지. 역생성은 "이 텍스트에서 읽히는 기획"이지 사실 고증이 아니다.
- **결말 누출 금지(AM-1, 최상위 규칙)**: logline·premise·core_conflict에 결말·최종 반전·해소 서술 금지. 위반 시 `premise→arc` 학습쌍이 창작이 아니라 요약 역변환으로 퇴화한다. ending 서술은 synopsis_full 전용. 파일럿 스팟체크의 FAIL 기준.
- 이중 floor: 자유서술 ≥40자, logline ≥8자.

**게이트(AM-5 결정론 원칙)**: `tools/current/verify_planning_layer.py` — FAIL 사유는 오프라인 결정론 항목만: ①필수키/enum ②floor ③scene_no 실재 ④by 태그 ⑤결말 키워드 휴리스틱(결정론 사전 기반). 임베딩 기반 로그라인 교차중복 검사는 별도 리포트 **WARN**(키 없이 CI 가동 보장). ERRORS 0 + WARN 보고.

### §4b. DR-1b — 구조 열화 합성 (AM-2 신설)
완성 아크·기획에서 **등급화 열화판** 생성: L1 복선 제거 / L2 인과 절단 / L3 긴장 평탄화 / L4 동기 삭제. 구조 층위 쌍대 학습(DPO)의 rejected 원천 + 기획 변별("좋은 기획 vs 나쁜 기획") 대조군. 방식은 M1 자격검정(명작>등급화 열화 단조 변별, 실증 완료)의 재사용 — 신규 방법론 아님. 산출: `seqcard_ko/degraded_planning/<작품>.<등급>.json` (합성물임을 by 태그에 명시, 정본 트리와 격리). 1차 규모: 10작×3등급. 한계 인지: 강열화의 변별력 포화(무가중도 만점) 실측이 있으므로, 박빙 변별은 난이도 사다리 L3~L4에서 별도 판정.

**학습쌍 수확 (기획 방향)**: `premise+genre → FullSeriesArc` / `logline+planning_intent → EpisodeArc 열` / `synopsis_full → 회차 경계`. 수확 스크립트는 DR 공통 §9.

**실행 순서**: 대장금 파일럿 1작(brief2prose 기저와 정합) → 사용자 승인 → CANONICAL 23작(Sonnet 병렬, 자립 브리프 첨부) → 70작 확산.

### §5. DR-2 — AlignmentLayer 확장 (seqcard↔원문 씬 정렬)

**산출 경로**: `seqcard_ko/alignment/<작품>.alignment.jsonl` (씬당 1행)

**스키마 `SourceSceneAlignmentRecord`** (EXT6 형식 승계):
```json
{"work_id":"대장금","scene_no":1,"source_file":"Scripts/.../대장금_01.txt",
 "cardinality":"1:1|1:N|N:1",
 "anchors":[{"heading":"#1 S 내금위 훈련장","line_start":12,"line_end":58}],
 "match_method":"heading|embedding|manual","confidence":0.97,"by":"align_scenes v1"}
```
**카디널리티(AM-3)**: seqcard 씬 구분(직접독해)과 파서 씬 구분은 1:1이 아니다(몽타주 분할 1:N, 슬러그 미스 병합 N:1 — 미생 기실측). `anchors` 배열로 다중 스팬 허용, 1:1 강제 금지.
**verbatim 정책(불변)**: 허브에는 인덱스(파일·라인 범위)만. 원문 스팬 텍스트는 로컬 전용 — 수확된 brief2prose 쌍의 completion(원문)도 로컬 전용, 허브에는 쌍 인덱스만.

**도구**: `tools/current/align_scenes.py` — 1차 씬헤딩 번호·슬러그 매칭 → 2차 임베딩(코사인, emb_cache 재사용) 후보 → 저신뢰만 수동 큐(`alignment/_MANUAL_QUEUE.json`). 미생 슬러그헤딩 파싱미스(기지 이슈) 같은 파서 갭은 정렬 실패 통계로 자동 표면화.
**캘리브레이션(AM-4)**: **brief2prose 479쌍(7작)을 정렬기 골드셋으로 사용** — 정밀도-재현율 곡선을 실측해 confidence 임계를 사전등록 후 고정(v1.0의 0.6 임의값 폐기). 추가 비용 0.

**DoD(사전등록)**: 골드셋 캘리브레이션 리포트 1건(임계 확정) + CANONICAL 23작 정렬률 ≥90% + 무작위 스팟체크 100건 오정렬 ≤2% + **confidence 하위 10% 수확 제외(AM-6 안전 마진)** + brief2prose 수확 쌍 ≥10,000(1차)·≥20,000(70작 완료 시).

### §6. DR-3 — 심사·승격 (PASS_CANDIDATE 46작 + v1→v2)

**심사 프로토콜(작품당)**: ①무작위 3화×10씬 원본 대조 스팟체크(직접독해 근거 실재 확인) ②v1 게이트 + 의미검사 v2 재실행 ③밀도 지표(GRAPH_DENSITY_FLOOR) 확인 → 3판정: **승격 후보 / 보완 후 승격 / 보류**. 심사 결과는 `provenance/promotion_review_<날짜>/<작품>.review.json`. **사용자 최종 승인 없이 CANONICAL 승격 없음(기존 정책 불변).**

**v1→v2 승격**: state_headline 채움 + ARC_STATE_ENUM/REL_STATE_ENUM 정합화. 기존 정책대로 **별도 승인 후 일괄** — 승격 스크립트(`upgrade_v1_to_v2.py`) + 전후 diff 감사 리포트 의무. Track1 밀도보강 완료 작품부터 처리(이중 작업 방지).

**DoD**: 심사 46작 완료율 및 판정 분포 보고 + 승격분 v2 게이트 ERRORS 0.

### §7. DR-4 — 명성 메타데이터 + 장르 균형

**산출**: `seqcard_ko/acclaim/acclaim.json` (작품당 1행)
```json
{"work_id":"하얀거탑","year":2007,"network":"MBC","episodes":20,
 "peak_rating":null,"avg_rating":null,"awards":["백상 대상"],
 "genre_norm":["의학","권력"],"era_bucket":"2000s","source":"공개 출처 URL/명"}
```
- **공개 팩트만**, source 필드 의무. 수치 미확인은 null(추정 금지).
- `genre_norm`은 닫힌 enum(장르 통제어휘 v1을 본 트랙에서 제정 — 15±5개).
- 연결: corpus_ko `meta_gt.py`의 잠정 GT를 본 데이터로 교체 → EXP-D(가중학습 LOO-CV) 재실행으로 신뢰도 상향. 2축 품질라벨(흥행=긍정)의 권위 원천.

**장르 균형 리포트**: 70작의 장르×시대×형식 분포표 → **잔여 30작 선정 기준**(커버리지 빈칸 우선). 특히 현 코퍼스의 OTT 단편형(8~12부) 공백을 명시.

**DoD**: 70작 acclaim 100% + 균형 리포트 1건 + meta_gt 교체 후 EXP-D 재실행 결과.

### §8. DR-5 — 은닉 시험지 + 인간 GT 최소 킷

**은닉 시험지(최신작 2~5편)**:
- 선정 기준: 2020년 이후 · OTT 8~12부 ≥1편 · 장르 분산 · 평단/흥행 검증작.
- **사전학습 누출 프로브 의무(AM-6, 선정 전)**: 베이스 모델(GPT/Claude/8B)에 제목·인물만 주고 후속 화 서술을 요구 → 실제 회차와 사건/n-gram 일치 검사. 오염(회상 가능) 판정 시 해당 작품 기각, 덜 알려진 작품으로 교체. 유명작은 M2가 창작이 아닌 **회상**을 측정하게 되기 때문(기존 M2 누출가드와 동일 사상). "검증된 작품성 + 낮은 회상 가능성" 균형은 대본 비공개 OTT 작품 우선으로 해결.
- **학습 격리를 게이트로 강제**: `source_lock`에 상태 `EVAL_HOLDOUT` 신설 — 해당 작품은 학습쌍 수확·RAG 인덱스·닻(anchor)·재가중 어디에도 유입 금지. 신설 게이트 `G_EVAL_HOLDOUT_ISOLATION`: 수확 파이프 출력에서 holdout work_id 검출 시 FAIL.
- 용도: **M2 구조 벤치 전용** — N화까지 제공, N+1화 씬/시퀀스 설계 생성 vs 실제 회차 구조 쌍대 비교. "고전 연료→현대 창작" 전이의 판정 장치.
- 봉인: 입수 즉시 sha256 고정 + EVAL_HOLDOUT 등록(분석은 Stage01~04 정상 수행하되 수확만 차단).

**인간 GT 최소 킷 (작가 1명부터 가동)**:
- 형식: **쌍대 양자택일만**(점수표 금지 — 절대채점 무효 실측이 근거). 세션당 ≤20쌍.
- 축 2종: ①구조 축 — "N화까지 읽었을 때 다음 화 설계로 더 타당한 쪽" ②문체 축 — 정전 근접("이 발췌와 더 가까운 쪽").
- 저장: InterventionEvent 스키마 재사용(type=annotate), `human_gt/judgments.jsonl`. 동의서 1p 동봉.
- 위치 무작위·박빙 쌍 양방향 2판정(기존 쌍대 프로토콜 그대로).

**DoD**: 시험지 봉인 완료(sha+격리 게이트 PASS) + 킷 문서·수집 스크립트 + 1차 인간 세션 1회(≥20판정).

### §9. 공통 — 학습쌍 수확 명세 + 의존 그래프
═══════════════════════════════════════════
**수확 스크립트**: `tools/current/harvest_pairs.py` — 계층쌍 공통 포맷:
```json
{"pair_type":"premise2arc|arc2episodes|episode2seqs|seq2beats|brief2prose",
 "work_id":"...","input":{...},"output":{...},"split":"train|val|HOLDOUT제외","provenance":"..."}
```
- split은 작품 단위(씬 단위 누출 금지). EVAL_HOLDOUT 작품은 산출 자체가 게이트 차단.
- 신설 게이트 3: `G_PLANNING_LAYER`(DR-1) · `G_ALIGNMENT_COVERAGE`(DR-2 ≥90%) · `G_EVAL_HOLDOUT_ISOLATION`(DR-5).

**의존·순서 (AM-7 재산정)**:
```
[1순위] DR-2 (골드셋 즉존·즉시 연료) ──┐
[2순위] DR-1 파일럿(대장금)+DR-1b ────┼─→ §9 수확 → DR Exit Gate → 구조 loop-C/M2 (엔진 트랙)
[3순위] DR-4 (병렬 소액) ─────────────┘
[병렬] DR-3 — Track1 밀도보강 완료 작품부터 묶음 심사(같은 작품 2회 열지 않음)
[대기] DR-5 — 개발자 구매 결정 시 (누출 프로브 → 봉인)
```
**DR Exit Gate(AM-7, 사전등록)**: 엔진 트랙 소비 개시 조건 — ①수확 쌍 ≥20,000 ②CANONICAL ≥40작 ③홀드아웃 봉인 ≥2편(프로브 통과) ④acclaim 100% ⑤DR-1b 열화 10작×3등급. 미달 항목은 사유와 함께 부분 개시 승인을 사용자에게 요청.
**비용 상한(AM-9)**: DR-1 검수 LLM 총 $35 · DR-2 임베딩 재사용 원칙(신규 $10 상한) · Sonnet 병렬 슬롯은 Track1 밀도보강과 주간 분할. cost_cap 파라미터 의무(기존 규약).

**100작 "충분성"의 실측 판정(권고)**: 30/50/70작 부분집합 학습 → M2 성능 곡선. 평탄화 지점이 "충분"의 정의 — 곡선이 답을 주면 잔여 저작·구매 배분을 조정한다.

### §9.5 발전 방향 — 실험 사다리 E1~E5 (본 로드맵의 소비처, 다음 단계 개발의 정본 경로)
═══════════════════════════════════════════
본 로드맵이 만든 데이터는 아래 5실험이 소비한다. 각 실험은 최종 목표(자율 기획·구성·창작·생성)의 한 능력을 실측으로 확정하며, 실패 시 원인이 능력 단위로 국소화된다. **이 사다리가 v14.0.0 이후 엔진 트랙의 다음 단계 발전 방향 정본이다.**

| 실험 | 입력 → 출력 | 검증 능력 | 판정 방식 | 데이터 의존 |
|---|---|---|---|---|
| **E1 정렬 검증** | 정렬기 vs brief2prose 골드셋 479쌍 | (연결 신뢰도) | 정밀도-재현율 ≥90% (AM-4) | 즉시 가능 |
| **E2 브리프→산문** | SceneCard(intent_gist 등) → 산문 생성 vs 실제 원문 | **창작(표현)** | 쌍대 + DPO 재학습(4070 5/5 ADOPT 검증 경로 재사용) | DR-2 수확 ≥1만 쌍 |
| **E3 다음 시퀀스 설계** | EpisodeArc+직전 카드열 → 다음 SequenceBlueprint·SceneCard 열 vs 실제 | **구성** | 구조 쌍대 — 복선 회수·인과·긴장을 공식(SceneFeature·NKG)으로 **결정론 판정**(심판 편향 우회) | DR-2 + 정본 확대(DR-3) |
| **E4 전제→아크** | WorkPlanningCard(결말 없는 전제) → 시리즈/회차 아크 vs 실제 + DR-1b 열화 | **기획** | 쌍대 + 열화 대조(좋은/나쁜 기획 변별) | DR-1·DR-1b |
| **E5 통합 최종** | 은닉 최신작 N화 → N+1화 전체(아크→시퀀스→카드→산문) vs 실제 방송분 | **기획+구성+창작 통합** | 블라인드 쌍대, 박빙은 인간 GT(DR-5 킷) | DR-5 + E2~E4 통과 |

- **순서**: E1(즉시) → E2(DR-2 직후) → E3 → E4 → E5. 병행: 30/50/70작 부분집합 학습 곡선으로 "100작 충분성" 실측(§9).
- **전망의 정직한 구분**: E1·E2는 선행 실증(골드셋 실존·4070 ΔW 5/5)으로 통과 확률 높음. **E3·E4가 본질적 미지수이자 본 프로젝트의 승부처** — 구조 생성 능력은 아직 어디에서도 실증된 바 없다. E5는 인간 판정 필수.
- **성공 정의(사전 합의)**: E2 통과="구성을 주면 창작하는 모델"(제품 성립) / E3="구성하는 모델" / E4="기획하는 모델" / E5=블라인드에서 인간 심사자가 실제 방송분을 체계적으로 골라내지 못함. 최종 수위는 2층: 직업적 대등(프로 품질 블라인드 대등) → 예술적 수준(전형성 무보상 M3 + 인간 GT로 계속 상향).
- 데이터 트랙(DR)과 실험 트랙(E)의 접점 = **DR Exit Gate**(§9): 통과 후 E2 개시.

### §10. 자기 점검 (논리적 약점)
- DR-1 역생성은 사후 합리화 위험 — 명작 한정이므로 "성공한 기획의 재구성"으로 유효하나, 실패작 대조군이 없어 "좋은 기획 vs 나쁜 기획" 변별 학습은 불가. 열화 합성(기존 M1 방식)으로 보완 예정.
- DR-2 임베딩 정렬 오류가 brief2prose에 전파될 수 있음 — confidence 필드·수동 큐·스팟체크 2% 임계로 방어. 파서 기지 이슈(미생 슬러그)는 정렬 실패로 표면화되므로 은폐되지 않음.
- DR-4 고전 작품 시청률은 집계 기준이 시대별로 상이 — era_bucket 내 상대 서열로만 사용, 절대 비교 금지.
- DR-5 인간 GT n은 소량 — 방향 발견용이지 절대 타당성 입증 아님(기존 실측 문서와 동일 한계 명시).
- 본 문서는 데이터 트랙이므로 V버전을 점유하지 않음. 엔진 측 소비(구조 loop-C·M2)는 별도 버전맵에서 할당.
