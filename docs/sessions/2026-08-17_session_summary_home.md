## 3. ★CT-12A/B — 경계 종점 타당성 위기 (오늘의 핵심)
**동기**: 세 번 연속 "AI가 정답을 못 맞힌다"가 나오자 **정답 자체의 신뢰도**를 물었다.
**선행 조사(공시)**: 코퍼스에 **독립 재분할 사례 0건** — 국희 재저작 20쌍은 좌표 불변 계약으로 경계 100% 동일, V24 구판 대비 **공통 1,724회차 상이 0건**. → **경계 라벨은 단일 주석·신뢰도 미검증**(신규 결함 A).
**측정**(9103846→84bc758): 격리 주석자 2인이 **원문만** 읽고(정답 비접촉) 4회차 재분할.
| 지표 | 값 |
|---|---|
| **R1 주석자 A↔B** | **0.737** |
| **R2 주석자↔정본** | **0.426** |
| 산술 등분↔정본 | **0.704** |
→ **원문 정독한 전문 주석자보다 아무것도 안 보는 등분이 정본에 더 가깝다.** 사전등록 규칙 발동: "R2 ≪ R1 → 정본 저작 지침 재검토". **종점 오염 확정**(신규 결함 B).
**해석**: CT-11 계열 생성 팔(0.42~0.49)은 **독립 전문 주석자의 정본 재현율(0.43)과 동급** → 각 실험의 불성립 판정은 유지하되 **"능력 부족" 해석은 ★유보 강등**.
**CT-12B 전수 진단**(d5d877e): 오라클 k 등분의 정본 재현율 **1,814회차 평균 0.514 · 완전일치 11.6% · ≥0.8 20% · <0.5 48%**. 작품별 극단(라이벌 0.97·베토벤 0.94 ↔ 여우각시별 0.22·식객 0.27). → **즉시 적용 규칙 3: ①경계 실험은 등분재현율로 층화 ②저작 검수 지표로 채택(구조의 얕음 탐지) ③학습·검색 표집은 내용주도 회차 우선.**
**균형 잡힌 판단(개발자 문답 반영)**: "정본이 틀렸다"는 결론은 **아직 성립 불가**. 반대 증거 3 — ①등분으로 48%는 0.5도 재현 안 됨(내용이 경계를 정함) ②작품 내 리듬 일관(R_work 0.59) ③sequence_intent 16,059/16,060 고유·value_shift 96.5% 고유(경계마다 판단문 존재). 또 제 주석자는 **한 줄 지침**만 받았고 정본 저작자는 상세 절차를 따랐다(지침 비대칭). **정확한 서술 = "암묵 표준으로 저작됨, 명문화·검증 안 됨, 약 20%는 관성 의심".**

## 4. ★시퀀스 표준 v1 제정 (6c10a2b) — 오늘의 산출물
**진단**: GPT `sequence_plan_candidate.schema.json`은 **필수 8필드는 규정하나 경계 규칙 없음**. 우리 `AUTHORING_SPEC.md`는 **씬 경계만** 규정. → **양 트랙 어디에도 시퀀스 단위 정의가 없다**(CT-12A 불일치의 근본 원인).
**정의**: 시퀀스는 **하나의 극적 거래** — 입구·출구의 가치 부호가 다른 씬들의 **최소 연속 묶음**. 판정문: *"이 묶음을 통째로 지우면 회차의 상태 서술이 바뀌는가?"*
**경계 규칙 B1~B5**(가치 결제·정보 상태 전환·주도권 역전·서사적 도약·플롯 전환) + **안티패턴 3금지**(등간격 맞추기·장소만으로 끊기·브레이크에 기계적 정렬).
**입도 규약**: 최소 2씬, **완결 가치 전환은 시퀀스당 1건**. 코퍼스 중앙값(8~9시퀀스/7.2씬)은 목표 아닌 사후 점검용.
**필드**: 후판 10필드(CT-07 실증) + **신설 `boundary_reason`**(B코드+근거 씬번호 — 없으면 경계는 검증 불가).
**절차**: 기획→구성→구조화→설계→창조 각 단계 산출·판정 규정. **게이트 G1~G5**(결제 유일성·경계 근거 필수·**등간격 경보 cv<0.08**·인물 접지·정보 원장 정합).
**합격 조건(미충족 시 v1 제안 상태 유지)**: **CT-12C** — 본 표준을 지침으로 준 독립 주석자 2인 재분할에서 **R1 0.737 → 0.85 이상**.
