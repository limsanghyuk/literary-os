# 채점 규약 v2 — 요소 문법 표준 + 조정자 절차 (2026-08-09, 집 Fable 초안)

**문서 ID**: LOS-SCORING-PROTOCOL-V2-DRAFT · 근거: D-53(경계 요소 재현성)·D-54(이진 일치도 기저율 팽창) · 개발자 지시(08-09) "진행하라"
**정당화 원칙 준수**: 본 개정의 모든 조항은 CT-08A·CT-07R 채점자 자기보고가 지목한 **실패 양식**(불성립 절 해석 갈림·복합 요소 부분 충족·역할 역전 허용 범위)과 D-53/D-54의 **구조적 결함**에서만 유도되었다. 어느 조항도 관측된 Δ·r 값을 유리하게 만들기 위해 선택되지 않았으며, 본 문서는 Δ 수치를 인용하지 않는다.

## 1. 요소 문법 v2 (Element Grammar)
실패 양식 3종을 각각 문법으로 봉쇄한다.
**G1. 원자 명제 분해** (↳복합 요소 부분 충족 문제): 요소는 서브 명제 배열로 저작한다. 각 서브 명제는 예/아니오만 가능한 단문. 요소 판정 = 서브 전부 1일 때 1(보수 유지). 채점·불일치 진단은 서브 단위로 국소화된다.
```json
{"cat":"goal","subs":[
  {"id":"s1","claim":"<주체 역할>이 <행위>를 시도한다"},
  {"id":"s2","claim":"그 시도가 <대상/결과>에 닿는다"}],
 "role_swap":"allow|forbid", "fail_if":["<폐쇄 목록>"], "not_judged":["<명시>"]}
```
**G2. 불성립 절 폐쇄 목록화** (↳불성립 절 해석 갈림): `fail_if`는 "다음 중 하나가 텍스트에 성립하면 0"의 **폐쇄 목록**만 허용. 서술형 금지. 요소-로컬 규칙이 상위 지침과 충돌하면 **요소-로컬 우선**을 규약 수준에서 고정.
**G3. 역할 기반 주체 + 역전 플래그** (↳역할·주체 역전 허용 범위): 주체는 인물명이 아니라 역할 서술로 쓰고, `role_swap` 플래그를 요소마다 의무 명시. 미명시 요소는 채점 투입 금지.
**G4. 근거 인용 의무**: 채점자는 1로 판정한 서브 명제마다 텍스트 행 인용 1개를 남긴다(0은 불요). 조정·감사의 재료.

## 2. 채점 절차 (2단)
**1단 — 독립 3인**: v2 요소로 블라인드 독립 채점(서브 단위 0/1+근거).
**2단 — 조정자(adjudicator)**: 3인 서브 단위 불일치 요소만 조정자에게 간다. 조정자는 **원 채점 라벨·채점자 신원을 보지 못하고** 요소+텍스트만 받아 재판정하며, 그 판정이 최종이다. 다수결 폐지 근거: D-53이 보인 것은 경계 요소에서의 계통적 갈림이므로 다수결은 우연에 판정을 맡긴다 — 조정은 갈림 지점을 명시적 재해석 1회로 닫는다.
**조정자 반려권**: 조정자가 "요소 자체 결함(문법 위반·이중 해석)"으로 반려 가능 → 해당 요소는 채점 제외+결함 등재. **반려율 >10%면 정답표 재저작 발동**(실험 무효 아님 — 도구 결함의 국소화).

## 3. 신뢰도 게이트 재정의
- 게이트 지표 = **비자명 쌍별 일치도**(D-54 반영 — 명목 일치도는 보고만 하고 게이트에 사용 금지).
- **1단 일치도 ≥ 0.80**(스크리닝) AND **조정 후 잔여 불일치 0**(정의상 충족) AND **반려율 ≤10%**.
- 0.90→0.80 완화의 정당화(관측치 무관): v1에서 1단 일치도는 유일한 신뢰 장치였으나 v2에서는 **조정 단계가 최종 신뢰를 담당**하므로 1단의 지위가 "최종 게이트→스크리닝"으로 바뀐다. 절차 신설에서 유도된 변경이며, 0.80조차 미달하면 조정 이전에 요소 문법이 실패한 것이므로 재저작으로 돌아간다.

## 4. 시행 순서 (원장 "순서 고정" 이행)
1. **캘리브레이션**: CT-01 정답표에서 20요소를 v2 문법으로 재저작 → 3인+조정 파일럿 → 1단 비자명 일치 ≥0.80 확인. 미달 시 문법 재개정(수치 인용 없이).
