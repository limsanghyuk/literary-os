### 반드시 지킬 것
- **좌표 불변**: 내용 6필드 외에는 1바이트도 바꾸지 않는다. 배열 길이·순서·씬별 명제 개수도 좌표다. merge.py 가 강제한다.
- **저작 순서**: event → info_shift → cast → plant_payoff → scene_notes. cast 쓸 때 event 를 가린다(F2 차단).
- **파일 생성은 bash heredoc 으로만**. `C:\claude\...` 경로 Write/Edit 는 조용히 잘린다. 위임 프롬프트에 반드시 명시.
- **회수보유% FLAG 은 무시**. 정본에서 `plant_payoff` 가 빈 시퀀스에는 배열 불변 계약상 넣을 수 없다. 회차 단위에서 해소 대상이 아니다.
- **원문 유출 금지**: `rework/**/packets/`, `rework/authored/` 는 원문 축자를 담는다. 허브 커밋 금지.

## 3. 손대면 안 되는 것

- **결혼못하는남자(0.779) · 공주가돌아왔다(0.766)** — 보류 2작이지만 **깊이로는 합격**이다. 보류 사유는 라인앵커/소스해시 결속뿐. **내용 재저작 지시 금지.** 필요한 것은 앵커 재산출이다.
- 합격 6작 전체 — 재저작 대상 아님.

## 4. 미해결 쟁점

1. **개와늑대의시간 경계 문제.** 지시서는 F3 을 "필드 수리 불가, 시퀀스 경계부터 재설정"으로 규정했다. 그러나 경계를 바꾸면 SceneCard 정합이 깨진다. 현행 타협안은 "경계 고정 + 내용만 수리 → 측정 → 그래도 0.748 미달이면 한계로 기록". 착수 전에 결정할 것.
2. **합격선 0.748 미검증.** 앵커 1점. 값 자체를 검증하려면 다점 절단점 실험이 필요하다.
3. **깊이 항의 편입 게이트 반영.** 현재 편입 게이트에 깊이 항이 없다. 101번째프로포즈(0.248)가 편입된 원인이 이것이다. 회차 단위 다양도 하한을 게이트에 추가해야 한다.
4. **CT-09 앵커 교체.** 너의목소리가들려 → 내여자친구는구미호. CT-08A-R 판정 이후 등록.
